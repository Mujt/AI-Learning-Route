# 类型转换（input 拿到的都是字符串）
num = int("20") # "20" → 20

函数 def：封装逻辑，反复调用

def add(a, b): # 定义函数：名字 add，输入 a、b
return a + b # 返回结果
result = add(3, 5) # 调用：把 3、5 传进去
print(result) # 8
  • def 名字(参数): → 定义一个函数
  • 名字(...) → 调用函数
  • return = 把结果送出来；
    不写 return 就返回 None
  • 先看名字猜用途：
    send_email() 发邮件、get_user() 拿用户

5.2

参数的花样（AI 代码里常见）

def greet(name, greeting="你好"): # 默认参数
print(f"{greeting}，{name}")
greet("张三") # 你好，张三
greet("张三", "早上好") # 早上好，张三
def add(*args): # *args = 任意多参数
return sum(args)
def show(**kwargs): # **kwargs = 任意"名字=值"
for k, v in kwargs.items():
print(k, v)
  • greeting="你好" = 默认参数，不传就用默认值
  • *args = 任意多个参数
  • **kwargs = 任意多个"名字=值"
  • 框架代码里到处都是，看到它们 = 知道"灵活收参数"就够了

为什么必须认识"类"？

6.2

类的标准长相（认识这四个部分）

class Student:
def __init__(self, name, score): # ① 构造：造人的时候执行
self.name = name # ② self.xxx = 自己的数据
self.score = score
def say_hello(self): # ③ 方法：会做的事
print(f"我是{self.name}")
s = Student("张三", 95) # ④ 创建对象（自动调 __init__）
s.say_hello() # 我是张三
  • 一看 class 名字 → 什么"物种"
  • 二看 __init__ → 造对象要传哪些参数
  • 三看 self.xxx → 对象有哪些数据
  • 四看 def 方法 → 对象会做哪些事
self = 对象自己。__init__ 是 Python 里最重要的函数——类的"出生证明"。

继承：新图纸抄旧图纸

class Animal:
def __init__(self, name):
self.name = name
def speak(self):
print("...")
class Dog(Animal): # Dog 继承 Animal
def speak(self): # 重写：狗有自己的叫法
print(f"{self.name}汪汪！")
d = Dog("旺财")
d.speak() # 旺财汪汪！
  • class Dog(Animal) = "Dog 继承了 Animal"（括号里是父类）
  • 读框架关键：class 我的Agent(BaseAgent) = 继承现成的，只改一小部分
  • super().__init__(...) = 调父类构造（先让老爸把基础建好）

Agent/框架核心

步骤3（加分）：Python 辅助脚本

# analyze.py —— 统计一段 Python 代码的基本信息
import sys
def analyze(code):
lines = code.split("\n")
non_empty = [l for l in lines if l.strip()]
funcs = [l for l in non_empty if l.strip().startswith("def ")]
classes = [l for l in non_empty if l.strip().startswith("class ")]
print("代码总行数:", len(lines))
print("非空行数:", len(non_empty))
print("函数数量:", len(funcs))
print("类数量:", len(classes))
for f in funcs:
print(" 函数:", f.strip().split("(")[0].replace("def ", ""))
if __name__ == "__main__":
code = sys.stdin.read() # 读取传入的代码
analyze(code)
  • 用今天学的知识：函数、列表推导式、for 循环、import
  • 在 SKILL.md 里加一句："先运行 analyze.py 传入代码，把统计结果作为讲解开头"
  • 这样 Skill 就真的"会干活"，而不只是让 AI 动嘴
真实 Skills 结构：SKILL.md（让 AI 知道怎么用）+ 辅助脚本（真正干活的工具）。

FAQ（上）

  • Q1：两个小时的语法会不会太少？
    不会。目标是"读懂"不是"熟练写"。真正的写法、排错、优化，未来实践中遇到再学。读代码需要的语法量，2 小时足够覆盖 90%。
  • Q2：我连 self 都还没完全懂，能继续吗？
    完全能。self 只需要记住"对象自己"这一个理解就够读了，剩下的一边读项目一边自然就懂了。
  • Q3：Skills 和第1周学的有什么区别？
    第1周是"会用现成 Skills"（装别人的）；本课是第一次自己写——把重复性提问固化成技能，这是"AI 协作开发者"的核心能力。

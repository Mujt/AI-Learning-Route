## 7.1 文本生成技术概述

### 7.1.1 自回归生成范式

现代文本生成的核心范式是**自回归（Autoregressive）**：

```
给定已生成前缀 w_1...w_(t-1) → 模型预测下一个词概率 P(w_t | w_1...w_(t-1))
→ 采样/选择 w_t → 追加到前缀 → 继续，直到 <eos> 或达到长度上限
```

### 7.1.2 解码策略（决定生成质量的关键）

| 策略 | 原理 | 特点 | 适用 |
|------|------|------|------|
| 贪婪解码 | 每步取概率最高词 | 确定性高但重复、呆板 | 摘要、翻译 |
| 束搜索 | 保留 Top-B 候选路径 | 接近全局最优，易重复 | 翻译、摘要 |
| **温度采样** | 按 softmax(logits/T) 采样 | T 高多样、T 低稳定 | 创意文本 |
| **Top-K 采样** | 只从概率前 K 个中采样 | 避免低概率垃圾词 | GPT-2 标配 |
| **Top-P（核采样）** | 累计概率达 P 的最小集合采样 | 动态裁剪，现代主流 | ChatGPT 默认 |
| 重复惩罚 | 对已出现词降权 | 减少重复 | 长文生成 |

**现代模型默认推荐**：`temperature=0.7 + top_p=0.9`（OpenAI 默认）。

### 7.1.3 文本生成的历史脉络

```
N-gram 统计语言模型（1950s-）
→ RNN/LSTM 语言模型（2010s）—— 字符级/词级生成
→ Transformer（2017）—— 大规模预训练（GPT/BERT）
→ 大模型时代（2020s）—— 指令遵循、长文、多模态
```

## 7.2 莎士比亚风格文本生成实战

### 7.2.1 项目目标

用**字符级 RNN/LSTM** 学习莎士比亚剧作的文本风格，训练后自动生成"伪莎士比亚"文字。

### 7.2.2 字符级模型原理

- 输入：文本转为字符序列（如 "To be or not to be" → 逐字符）。
- 模型：LSTM 逐字符预测下一个字符。
- 优点：无需分词、词汇表小（几十-几百字符）、可捕捉风格韵律。

### 7.2.3 PyTorch 实现

```python
import torch
import torch.nn as nn
import numpy as np

# 1. 数据准备
text = open("shakespeare.txt", encoding="utf-8").read()
chars = sorted(set(text))
char2idx = {c: i for i, c in enumerate(chars)}
idx2char = {i: c for c, i in char2idx.items()}
VOCAB = len(chars)  # 字符表大小

# 2. 字符级 LSTM 模型
class CharRNN(nn.Module):
    def __init__(self, vocab_size, hidden=256, n_layers=2):
        super().__init__()
        self.embed = nn.Embedding(vocab_size, hidden)
        self.lstm = nn.LSTM(hidden, hidden, n_layers, batch_first=True)
        self.fc = nn.Linear(hidden, vocab_size)

    def forward(self, x, state=None):
        out, state = self.lstm(self.embed(x), state)
        return self.fc(out), state

model = CharRNN(VOCAB, hidden=512, n_layers=2)
```

### 7.2.4 训练与生成

```python
# 训练：取长度为 SEQ_LEN 的序列，预测位移一位的下一字符
def train_step(model, batch, optimizer, criterion):
    x = batch[:, :-1]           # 输入序列
    y = batch[:, 1:]            # 目标：下一个字符
    logits, _ = model(x)
    loss = criterion(logits.reshape(-1, VOCAB), y.reshape(-1))
    optimizer.zero_grad(); loss.backward()
    optimizer.step()
    return loss.item()

# 生成：给定种子，温度采样
def generate(model, seed, length=500, temperature=0.8):
    model.eval()
    chars = list(seed)
    x = torch.tensor([[char2idx[c] for c in chars]])
    state = None
    for _ in range(length):
        with torch.no_grad():
            logits, state = model(x, state)
        logits = logits[0, -1] / temperature      # 温度缩放
        probs = torch.softmax(logits, dim=-1)
        next_char = torch.multinomial(probs, 1).item()   # 采样
        chars.append(idx2char[next_char])
        x = torch.tensor([[next_char]])
    return "".join(chars)

print(generate(model, "To be, or not to be: that is the question", 600))
```

### 7.2.5 参数调优实验

| 参数 | 影响 | 实验建议 |
|------|------|----------|
| temperature | 0.2 保守重复；1.0 创意乱；0.8 均衡 | 对比 0.3/0.8/1.2 |
| hidden size | 容量，过大过拟合 | 256-1024 |
| SEQ_LEN | 上下文长度，影响风格连贯 | 64-256 |
| 训练轮数 | 过拟合则"背课文" | 观察 loss 曲线 |

## 7.3 多模态大模型前沿综述

### 7.3.3 多模态幻觉问题

- **现象**：模型描述图像中不存在的物体/属性（"这张图里有只狗"——实际没有）。
- **成因**：训练数据中的图文噪声、模态间的信息不对称。
- **缓解**：更高质量图文数据、推理时校验、RLHF 对齐、检索增强（多模态 RAG）。

## 常见问题（FAQ）

**Q1：字符级模型和词级/子词级模型什么区别？**
A：字符级词汇表小、可捕捉拼写风格但序列长；词级序列短但词汇表大、OOV 问题；子词（BPE）是工业标准，兼顾二者。教学用字符级最简单直观。

**Q2：为什么采样生成的文本更有趣而贪婪生成很呆？**
A：贪婪/束搜索追求"最大概率路径"，趋于平庸与重复；采样引入随机性，保留语言的多样性与创造性。生成任务常用采样，判别任务常用贪婪。

**Q3：多模态模型目前最大的瓶颈是什么？**
A：①幻觉与可靠性；②复杂推理与物理常识；③多模态对齐的语义鸿沟；④长视频与实时交互的成本。这些都是活跃研究领域。

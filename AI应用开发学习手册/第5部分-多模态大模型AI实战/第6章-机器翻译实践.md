## 6.1 机器翻译概述与 Seq2Seq

### 6.1.1 任务定义

机器翻译（Machine Translation）：将源语言句子翻译为目标语言句子，属于**序列到序列（Sequence-to-Sequence）**任务。

### 6.1.2 传统 Seq2Seq（RNN 时代）

```
编码器（RNN）：读入源句，压缩为"语义向量"（最后一个隐状态）
解码器（RNN）：从语义向量开始，逐个词生成目标句

缺陷：
① 长句信息压缩丢失（语义向量容量有限）
② 无法对齐"源词的哪个部分决定了哪个目标词"
```

### 6.1.3 注意力如何解决

**Bahdanau Attention（2014）**：解码每个词时，不是只看最终语义向量，而是**动态关注源句的各个位置**：

```
生成 "猫" 时 → 注意力集中在源句 "cat" 位置
生成 "在" 时 → 注意力转移到 "on" 位置
```

Transformer 把这一思想极致化：**任意位置间的直接注意力**，翻译效果全面超越 RNN。

### 6.2.2 模型结构（完整 Transformer）

```python
class TranslationModel(nn.Module):
    def __init__(self, src_vocab, tgt_vocab, d_model=256,
                 n_heads=8, n_layers=6, d_ff=512, dropout=0.1):
        super().__init__()
        self.encoder = TransformerEncoder(
            nn.TransformerEncoderLayer(d_model, n_heads, d_ff, dropout),
            num_layers=n_layers)
        self.decoder = TransformerDecoder(
            nn.TransformerDecoderLayer(d_model, n_heads, d_ff, dropout),
            num_layers=n_layers)
        self.src_embed = nn.Embedding(src_vocab, d_model)
        self.tgt_embed = nn.Embedding(tgt_vocab, d_model)
        self.pos_enc = PositionalEncoding(d_model, dropout)
        self.out = nn.Linear(d_model, tgt_vocab)

    def forward(self, src, tgt, src_mask, tgt_mask, memory_mask):
        src_emb = self.pos_enc(self.src_embed(src) * (self.d_model ** 0.5))
        memory = self.encoder(src_emb, mask=src_mask)     # 编码源句
        tgt_emb = self.pos_enc(self.tgt_embed(tgt) * (self.d_model ** 0.5))
        out = self.decoder(tgt_emb, memory, tgt_mask=tgt_mask,
                           memory_mask=memory_mask)       # 解码+交叉注意力
        return self.out(out)
```

### 6.2.3 关键掩码

| 掩码 | 作用 |
|------|------|
| src_padding_mask | 忽略源句 padding |
| tgt_padding_mask | 忽略目标句 padding |
| tgt_mask（因果） | 预测时禁止看未来目标词 |
| memory_mask | 解码器对源句的可见性 |

### 6.2.4 训练循环

```python
import torch.optim as optim

criterion = nn.CrossEntropyLoss(ignore_index=PAD_IDX)
optimizer = optim.Adam(model.parameters(), lr=1e-3, betas=(0.9, 0.98), eps=1e-9)

def train_epoch(model, loader, optimizer, criterion):
    model.train()
    total_loss = 0
    for src, tgt in loader:
        # tgt_input = tgt[:, :-1]（不含 eos）；tgt_output = tgt[:, 1:]（不含 bos）
        optimizer.zero_grad()
        logits = model(src, tgt_input, src_mask, tgt_mask, memory_mask)
        loss = criterion(logits.reshape(-1, logits.size(-1)),
                         tgt_output.reshape(-1))
        loss.backward()
        torch.nn.utils.clip_grad_norm_(model.parameters(), 1.0)  # 梯度裁剪
        optimizer.step()
        total_loss += loss.item()
    return total_loss / len(loader)
```

**学习率调度（Transformer 标准）**：Warmup 4000 步，之后按步数平方根衰减：

```
lr = d_model^(-0.5) × min(step^(-0.5), step × warmup^(-1.5))
```

## 6.3 模型训练与评估

### 6.3.1 训练技巧总结

| 技巧 | 说明 |
|------|------|
| 数据增强 | 反向翻译、噪声注入、词替换 |
| 标签平滑 | label_smoothing=0.1 防过拟合 |
| 梯度裁剪 | clip_grad_norm 1.0 稳定训练 |
| 混合精度 | BF16 训练提速省显存 |
| 早停 | 验证集 BLEU 不再提升即停 |
| 多语言 | 中→英→中回译增强 |

### 6.3.2 BLEU 评估

**BLEU（Bilingual Evaluation Understudy）**：衡量机器译文与参考译文的**n-gram 重合度**：

```
BLEU = BP × exp( Σ p_n / N )   （n=1,2,3,4）
BP（简短惩罚）：译文过短时惩罚
p_n：n-gram 精确率

范围：0-100（常用百分比），现代系统 30-50（通用域）
```

```python
# 使用 sacreBLEU（标准实现）
from sacrebleu import corpus_bleu
bleu = corpus_bleu(hypotheses, [references]).score
print(f"BLEU: {bleu:.1f}")
```

### 6.3.3 其他评估指标

| 指标 | 说明 |
|------|------|
| chrF / chrF++ | 字符级重合，对形态丰富语言更稳 |
| COMET（神经网络） | 学习人类评分，与人工更相关 |
| TER | 编辑距离类指标 |
| 人工评估 | 忠实度、流利度、恰当性（最终标准） |

### 6.3.4 常见失败模式与对策

| 现象 | 对策 |
|------|------|
| 罕见词 OOV | BPE/SentencePiece 子词切分 |
| 长句漏译 | 训练时长度采样均衡、注意力头分析 |
| 数字/日期错误 | 数据后处理（数字占位符替换） |
| 术语不一致 | 术语表约束解码 |

## 常见问题（FAQ）

**Q1：现在还用自己训翻译模型吗？**
A：通用翻译直接调大模型 API 更简单；自训适合**垂直领域**（法律/医疗术语）或离线私有化场景。但本课程重点是理解 Transformer 原理，训练小模型是极佳实践。

**Q2：BLEU 分数越高越好吗？**
A：BLEU 与人工质量相关性约 0.7-0.8，但存在盲区（语义忠实、流畅性）。现在常用"BLEU 兜底 + 人工/LLM 评分"组合评估。

**Q3：为什么解码要加 <bos>/<eos>？**
A：<bos> 告诉模型"开始生成"，<eos> 标记结束；训练时用"位移一位"的技巧让模型学"预测下一个词"。

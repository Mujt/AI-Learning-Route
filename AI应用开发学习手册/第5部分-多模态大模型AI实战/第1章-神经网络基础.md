## 1.1 深度学习基础

### 1.1.1 神经元与前向传播

一个神经元：`y = σ(w·x + b)`，其中 w 权重、b 偏置、σ 激活函数。

**常用激活函数**：

| 函数 | 公式 | 特点 |
|------|------|------|
| Sigmoid | 1/(1+e⁻ˣ) | 输出 0-1，梯度易饱和消失 |
| Tanh | (eˣ-e⁻ˣ)/(eˣ+e⁻ˣ) | 输出 -1~1，缓解零中心 |
| ReLU | max(0, x) | 计算快、缓解梯度消失（最常用） |
| Leaky ReLU | max(0.01x, x) | 解决 ReLU 死亡问题 |
| GELU | 平滑 ReLU 变体 | Transformer 常用 |

### 1.1.2 损失函数与反向传播

- **损失函数**：衡量预测与真实差距。分类用交叉熵（Cross-Entropy），回归用 MSE。
- **反向传播（Backpropagation）**：链式法则求损失对各参数的梯度，再用优化器（SGD/Adam）更新参数。
- **梯度消失/爆炸**：深层网络中梯度连乘导致趋近 0 或爆炸，是深度网络训练的经典难题（Transformer 的残差连接与 LayerNorm 正是为此设计）。

## 1.2 全连接网络（FC）

### 1.2.1 结构

```
输入层（n 维）→ 隐藏层1（m 个神经元）→ 隐藏层2 → ... → 输出层（k 维）
```

每层输出：`h = σ(W·x + b)`，层与层之间**全连接**（每个神经元连接上一层的所有神经元）。

### 1.2.2 局限

1. **参数爆炸**：图像 224×224×3 展开为 15 万维，全连接参数量巨大。
2. **丢失空间结构**：展平操作破坏了像素的空间局部性。
3. **无法处理变长序列**：输入维度固定，难以处理文本/时序。

> 结论：图像用 CNN，序列用 RNN，通用特征提取后接 FC 做分类/回归。

## 1.3 卷积神经网络（CNN）

### 1.3.1 核心思想

**局部感受野 + 权值共享 + 平移不变性**：用卷积核（如 3×3）在图像上滑动扫描，同一卷积核共享参数，大幅减少参数量并保留空间结构。

### 1.3.2 三大操作

**① 卷积（Convolution）**：卷积核与局部区域逐元素相乘求和，生成特征图。

```
输入 5×5 图像 × 3×3 卷积核 → 输出 3×3 特征图
步长 stride=1，填充 padding=0
输出尺寸 = (W - K + 2P) / S + 1
```

**② 池化（Pooling）**：下采样降维——最大池化（取最大值，保留显著特征）、平均池化。

**③ 全连接**：卷积+池化提取特征后，展平送入 FC 分类。

### 1.3.3 经典 CNN 结构演进

| 网络 | 年份 | 关键贡献 |
|------|------|----------|
| LeNet-5 | 1998 | CNN 开山之作（手写数字） |
| AlexNet | 2012 | 深度 CNN + ReLU + Dropout + GPU（详见第 2 章） |
| VGG | 2014 | 小卷积核堆叠（3×3 反复堆叠） |
| GoogLeNet | 2014 | Inception 多尺度并行（详见第 3 章） |
| ResNet | 2015 | 残差连接解决深层退化（后续章节会看到残差是 Transformer 标配） |

### 1.3.4 PyTorch 实现基础 CNN

```python
import torch.nn as nn

class SimpleCNN(nn.Module):
    def __init__(self, num_classes=10):
        super().__init__()
        self.features = nn.Sequential(
            nn.Conv2d(3, 32, kernel_size=3, padding=1),  # 3通道→32特征图
            nn.ReLU(),
            nn.MaxPool2d(2),
            nn.Conv2d(32, 64, kernel_size=3, padding=1),
            nn.ReLU(),
            nn.MaxPool2d(2),
        )
        self.classifier = nn.Sequential(
            nn.Flatten(),
            nn.Linear(64 * 56 * 56, 256),
            nn.ReLU(),
            nn.Linear(256, num_classes),
        )

    def forward(self, x):
        return self.classifier(self.features(x))
```

## 1.4 循环神经网络（RNN）

### 1.4.1 核心思想

RNN 处理**序列数据**（文本、语音、时间序列），通过**隐状态（Hidden State）**在时间步之间传递信息：

```
h_t = tanh(W_hh·h_(t-1) + W_xh·x_t + b)
y_t = W_hy·h_t + b
```

每个时间步共享同一套参数（权重共享），输出依赖前面所有步的信息。

### 1.4.2 结构变体

| 变体 | 结构 | 用途 |
|------|------|------|
| 多对一 | 序列 → 单个输出 | 文本分类、情感分析 |
| 一对多 | 单输入 → 序列 | 图像描述（图像→句子） |
| 多对多（同步） | 序列 → 序列 | 词性标注 |
| 多对多（异步） | 序列 → 序列 | 机器翻译（Encoder-Decoder） |

### 1.4.3 RNN 的缺陷与改进

**① 梯度消失/长期依赖问题**：远距离信息经过多次连乘后梯度趋近 0，难以学习长距离依赖（"第 1 个词影响第 100 个词"）。

**② 改进方案**：

| 方法 | 机制 | 效果 |
|------|------|------|
| LSTM | 门控机制（输入门/遗忘门/输出门）+ 细胞状态 | 记住/遗忘可控，缓解长期依赖 |
| GRU | 简化 LSTM（更新门/重置门） | 参数更少，效果接近 LSTM |
| **Transformer** | 注意力机制直接建模任意距离依赖 | 彻底解决（现代主流） |

### 1.4.4 LSTM 门控直觉

```
遗忘门：决定丢掉哪些旧记忆
输入门：决定记住哪些新信息
输出门：决定输出哪些记忆
细胞状态 C_t 沿时间传递，梯度通过"加性"路径流动，缓解梯度消失
```

## 1.5 本章知识在后续课程的定位

```
全连接/CNN/RNN ──► 图像特征提取（多模态的视觉基础）
Transformer ──────► 文本/视觉统一的骨干架构
注意力机制 ───────► 序列建模的核心（LSTM 的替代者）
```

**为什么多模态课程要先讲这些**：多模态大模型（Qwen-VL 等）的视觉编码器本质是 CNN/Transformer 架构，文本侧是 LLM，理解基础网络才能理解"图像怎么变成 Token"。

## 常见问题（FAQ）

**Q1：都 2026 年了，还要学 CNN/RNN 吗？**
A：要。CNN 仍是视觉特征提取的主力（多模态模型的视觉塔），LSTM 仍是部分序列任务的好选择；更重要的是理解"为什么 Transformer 取代了 RNN"。

**Q2：CNN 和 Transformer 在视觉任务上谁强？**
A：Transformer（ViT）在大规模数据下更强，CNN 在小数据与归纳偏置上更稳。现代视觉模型常用"CNN 主干 + Transformer 解码"或纯 ViT。

**Q3：梯度消失为什么是深层网络的头号问题？**
A：反向传播是链式连乘，深度越大梯度越容易趋近 0，参数几乎不更新。残差连接、归一化、ReLU 都是为了缓解它。

## 10.2 项目实践方向（含验收标准）

### 方向 1：企业知识库问答系统
- **技术栈**：LangChain/LlamaIndex + Milvus + vLLM + Ragas
- **功能**：多格式文档问答、引用溯源、权限过滤、评估报告
- **验收**：忠实度 >0.8、检索命中率 >85%、响应 <3s

### 方向 2：行业智能体（HR / 电商 / 金融）
- **技术栈**：LangGraph + MCP + Dify/Coze
- **功能**：多 Agent 协作、工具调用、Human-in-loop 审批
- **验收**：任务成功率 >90%、转人工率 <20%、全链路可观测

### 方向 3：领域大模型微调项目
- **技术栈**：LLaMA-Factory + QLoRA + lm-evaluation-harness
- **功能**：领域数据收集 → 微调 → 量化 → 部署
- **验收**：领域测试集显著提升 + 通用能力无退化 + 显存达标

### 方向 4：多模态应用（图像/文档）
- **技术栈**：Qwen-VL + 多模态 RAG + Streamlit
- **功能**：图片问答、OCR、图文知识库、视觉质检
- **验收**：目标场景准确率 >90%、10 张测试图全部正确

> 建议：从"方向 1 + 方向 3"组合起步（覆盖面最广、岗位匹配度最高），再扩展 Agent 与多模态。

## 10.3 学习路线规划

### 10.3.1 分阶段路线

```
阶段 1（1-2 周）：认知与提示词
  通读第1部分 → 大量实操 Prompt → 熟悉 2 个模型 API
阶段 2（2-3 周）：RAG 核心
  实现 Naive RAG → 进阶优化 → 用 Ragas 评估
  → 用 Dify/RAGFlow 快速搭一个可演示项目
阶段 3（2-3 周）：Agent
  学 MCP → Function Calling → LangGraph 多 Agent
  → 做一个"研究助手"或"客服 Agent"
阶段 4（3-4 周）：微调与部署
  LoRA/QLoRA 微调小模型 → 评估 → 量化 → vLLM 部署
阶段 5（2-3 周）：多模态与项目整合
  Qwen-VL 微调 → 综合项目（知识库+Agent+多模态）
阶段 6（持续）：深入方向
  检索优化 / 推理优化 / 模型训练 / 多模态前沿
```

### 10.3.2 学习投入建议

| 投入 | 对应产出 |
|------|----------|
| 每天 2-3 小时 × 3 个月 | 可胜任 RAG/Agent 应用开发岗 |
| 6 个月（含 2 个完整项目） | 可胜任大模型开发/算法工程岗 |
| 1 年+（深度方向） | 专家/高级工程师 |

## 10.4 就业方向与技能要求

### 10.4.1 岗位地图

| 岗位 | 核心职责 | 对应模块 |
|------|----------|----------|
| **大模型应用开发工程师** | RAG/Agent/API 集成开发 | 第 1-3 部分 |
| **AI 产品经理** | 场景定义、评测、迭代 | 第 1、2 部分 |
| **大模型算法工程师** | 微调、对齐、评估 | 第 4、5 部分 |
| **推理优化工程师** | vLLM、量化、分布式 | 第 4 部分 |
| **多模态算法工程师** | VLM 微调、视觉任务 | 第 5 部分 |
| **AI 架构师** | 系统设计、选型、治理 | 全部 |

### 10.4.2 技能要求清单

**硬技能**：
- Python（必会）、PyTorch（会写会训）
- 向量数据库、RAG 框架、Agent 框架
- Docker/K8s 部署、模型推理优化
- 评测体系与数据分析

**软技能**：
- 业务理解（场景 → 技术方案）
- 工程素养（测试、文档、监控）
- 持续学习（技术迭代极快）

### 10.4.3 面试高频考点

```
① 手写注意力机制 / LoRA 原理
② RAG 优化策略（混合检索/重排/评估）
③ Agent 架构设计（ReAct 循环、多 Agent 协作）
④ 量化原理（PTQ/QAT 区别）
⑤ 微调 vs RAG 的选择
⑥ 场景题：设计一个企业知识库/客服系统
```

## 10.5 结语与行动建议

**技术不变的本质**：无论模型如何迭代，**"数据 → 模型 → 评估"的铁三角**与**"场景 → 架构 → 工程落地"的方法论**始终适用。

**最后的建议**：
1. **动手优先**：本手册每个"动手实践"都是为求职作品集准备的素材。
2. **构建作品集**：2-3 个带评估报告的项目，比 10 个 Demo 更有说服力。
3. **保持跟踪**：大模型领域月月有变化，关注官方文档与一线技术博客。
4. **从项目出发**：先定一个业务目标（如"给公司搭知识库"），再倒推学习。

> 祝你在 AI 应用开发的道路上稳步前行，把"会用 API"升级为"能造系统"。

# AI 应用开发学习手册

> 参照《AI 应用开发》课程大纲编写的系统性学习手册，融合全网高质量技术博客与实战经验，面向希望从零基础成长为 AI 大模型应用/开发/算法工程师的学习者。

## 手册定位

本手册严格对照《AI 应用开发 full.md》课程大纲，按 **5 大模块、36 个章节** 组织内容。每个章节均包含：

- **学习目标**：明确本章要掌握的核心能力
- **知识体系**：对大纲技术要点的系统化讲解
- **高质量博客推荐**：经网络筛选的权威技术文章（附链接与推荐理由）
- **动手实践**：可落地的练习建议与代码思路
- **常见问题（FAQ）**：学习中的高频疑问解答

## 适用人群

- 传统行业从业者，希望转型 AI 应用开发岗位
- 刚入门的程序员/产品经理，需要系统化的大模型知识体系
- 已有 API 调用经验，希望进阶 RAG、Agent、微调部署的高级开发者
- 需要冲刺大模型应用工程师/开发工程师认证的学员

## 学习路线

建议按以下顺序学习，每部分约 1-2 周：

```
第1部分 大模型应用设计基础（认知 + 原理 + 提示词）
   ↓
第2部分 RAG 设计与开发实战（知识库 + 检索增强生成）
   ↓
第3部分 Agent 智能体（低代码 + 协议 + 多智能体架构）
   ↓
第4部分 大模型微调与部署（数据 + 微调 + 量化 + 部署）
   ↓
第5部分 多模态大模型（视觉基础 + Transformer + 多模态实战）
```

> 建议：第 1、2 部分必须扎实掌握（对应 RAG 工程师岗位）；第 3 部分对应 Agent 工程师岗位；第 4 部分对应大模型算法工程师岗位；第 5 部分对应多模态算法专家岗位。

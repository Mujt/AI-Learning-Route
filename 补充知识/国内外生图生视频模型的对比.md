## 1. 概览与分类

### 1.1 任务类型定义

| 缩写 | 全称 | 说明 |
|------|------|------|
| T2I | Text-to-Image | 文本描述生成图片 |
| T2V | Text-to-Video | 文本描述生成视频 |
| I2V | Image-to-Video | 图片生成视频（图生视频） |
| V2V | Video-to-Video | 视频风格迁移与编辑 |
| T2I+V | Text-to-Image+Video | 文本同时生成图片与视频 |
| 3D | 3D Generation | 文本/图片生成 3D 模型 |

### 1.2 快速总览

| 类别 | 国外代表模型 | 国内代表模型 | 开源代表模型 |
|------|------------|------------|------------|
| T2I 闭源 | DALL-E 4, Midjourney V7, Imagen 3, Ideogram 3 | 即梦, 文心一格, 通义万相, 混元 | Flux.1, SD3.5, Skywork |
| T2V 闭源 | Sora 2, Veo 3.1, Gen-4, Kling 2, Dream Machine | 即梦视频, 通义万相视频, 混元视频, Vidu, Hailuo AI | CogVideoX, Step-Video, Wan 2.6 |
| I2V | Runway Gen-4, Pika 3, Kling 2, Luma Dream Machine | 即梦, 通义万相, Vidu | SVD, CogVideoX, AnimateDiff |
| 视频编辑 | Runway Gen-4, Pika 3, Adobe Firefly Video | 通义万相, 即梦 | — |
| 3D 生成 | Luma Genie, Meshy, TripoSR | 通义万相 3D | TripoSR, InstantMesh |

## 2. 国外生图模型

### 2.1 OpenAI — DALL-E 3 / DALL-E 4

| 属性 | 详情 |
|------|------|
| **开发公司** | OpenAI（美国） |
| **模型架构** | Diffusion Transformer（DiT）变体，结合 CLIP 文本编码器与自研 VLM 重描述（re-captioning）管道 |
| **是否开源** | 否，仅通过 API 和 ChatGPT 提供 |
| **计费方式** | ChatGPT Plus $20/月（含 DALL-E 3）；ChatGPT Pro $200/月（含 DALL-E 4）；API 按张数计费：DALL-E 3 标准 1024x1024 约 $0.040/张，HD 约 $0.080/张 |
| **最大分辨率** | DALL-E 3：1792x1024（横版）/ 1024x1792（竖版）；DALL-E 4：支持 2048x2048 |
| **突出能力** | 业界最强的提示词遵循（Prompt Following）和文字渲染（Text Rendering）；利用 GPT-4o/5 进行自动提示词重写，大幅提升普通用户的出图质量 |
| **优势** | 文字渲染精准度在一线模型中持续领先；与 ChatGPT 生态深度整合；DALL-E 4 支持多轮迭代编辑 |
| **劣势** | 美术质感（aesthetics）不如 Midjourney；API 不开放微调；速度较慢（单张 5-15 秒）；内容审查极其严格 |
| **适用场景** | 需要精准文字呈现的营销素材；非专业用户的快速出图；企业级 API 集成 |

### 2.2 Midjourney

| 属性 | 详情 |
|------|------|
| **开发公司** | Midjourney Inc.（美国） |
| **模型架构** | 基于扩散模型（Diffusion），V6 起引入自研架构改进细节与纹理生成，V7 进一步强化真实感与速度 |
| **是否开源** | 否，完全闭源 |
| **计费方式** | Basic $10/月（约 200 张快速出图）；Standard $30/月（无限慢速 + 15h 快速 GPU）；Pro $60/月（30h 快速）；Mega $120/月（60h 快速）；Turbo $600/年 |
| **版本** | V6（2023年底）、V6.1（2024）、V7（2025-2026，当前主力） |
| **最大分辨率** | 支持 2x/4x Upscale，最高可达 4096x4096+ |
| **突出能力** | 艺术质感和美学品质行业公认第一；强大的风格参考（Style Reference, `--sref`）和角色参考（Character Reference, `--cref`）功能；社区生态成熟（Discord 端 + Web 端） |
| **优势** | 无需复杂提示词即可生成高度美观的图片；风格控制力极强；持续快速迭代；V7 速度与质量双重飞跃 |
| **劣势** | 文字渲染能力弱于 DALL-E 4 和 Ideogram；仅通过 Discord/Web 访问，无官方 API（2026 年有传闻将推出 API）；对中国用户访问不便 |
| **适用场景** | 概念艺术、游戏原画、插画设计、品牌视觉探索；对美学要求极高的创意工作 |

### 2.3 Google — Imagen 3

| 属性 | 详情 |
|------|------|
| **开发公司** | Google DeepMind（美国） |
| **模型架构** | 级联扩散模型（Cascaded Diffusion），结合 T5-XXL 文本编码器；Imagen 3 引入 DiT 架构改进 |
| **是否开源** | 否，通过 Vertex AI 和 ImageFX 提供 |
| **计费方式** | ImageFX 免费（Google 账号）；Vertex AI API：约 $0.020/张（1024x1024）；Gemini Advanced $19.99/月（含 Imagen 3） |
| **最大分辨率** | 2048x2048 |
| **突出能力** | 照片级真实感（Photorealism）业界顶级；文本渲染接近 DALL-E 3 水平；多语言支持良好 |
| **优势** | 照片真实感极其出色，难以区分 AI 生成与实拍；在 Vertex AI 上提供企业级 SLA；与 Google 生态整合 |
| **劣势** | 艺术化风格能力不如 Midjourney；中国地区访问受限；API 可用区域有限 |
| **适用场景** | 电商产品图、广告素材、照片级场景生成；需要企业级 API 的大规模生产 |

### 2.4 Stability AI — Stable Diffusion 3.5 / SDXL / SVD

| 属性 | 详情 |
|------|------|
| **开发公司** | Stability AI（英国） |
| **模型架构** | SDXL：Latent Diffusion + UNet；SD3：Diffusion Transformer（DiT）+ 双文本编码器（T5 + CLIP）；SD3.5：改进 DiT + Flow Matching |
| **是否开源** | 是（Open Weights，非商业友好许可证：SD3.5 使用 Stability AI Community License，商业使用有限制） |
| **计费方式** | 自部署：免费（仅 GPU 成本）；Stability AI API：按张数计费，约 $0.003-0.010/张（SD3.5）；Replicate 等第三方托管平台也可使用 |
| **版本矩阵** | SDXL 1.0（2023）、SDXL Turbo（2023，实时生成）、SD3（2024）、SD3.5 Large（2024）、SD3.5 Large Turbo（2024）、SD3.5 Medium（2024） |
| **最大分辨率** | SD3.5 Large：1024x1024 原生，可 upscale；SDXL：1024x1024 |
| **突出能力** | 开源社区生态最成熟，ControlNet、LoRA、IP-Adapter 等生态工具丰富；SDXL Turbo 实现近实时出图（1 步采样） |
| **优势** | 完全自部署，数据私密；社区微调模型极多（CivitAI 上有海量 LoRA）；灵活可定制；成本最低 |
| **劣势** | SD3 发布早期因人体结构问题口碑受挫；文字渲染不如闭源模型；需要用户具备技术能力；SD3.5 许可证限制商业使用 |
| **适用场景** | 研究、教育、个性化定制出图；需要数据隐私的企业场景；批量低成本出图 |

### 2.5 Flux（Black Forest Labs）

| 属性 | 详情 |
|------|------|
| **开发公司** | Black Forest Labs（德国，Stability AI 前核心团队创立） |
| **模型架构** | 多模态 DiT + Flow Matching，结合双文本编码器（CLIP + T5-XXL）；直接预测 flow velocity 而非噪声 |
| **是否开源** | Flux.1 Schnell：Apache 2.0；Flux.1 Dev：非商业研究许可；Flux.1 Pro：闭源 API |
| **版本** | Flux.1 Pro（最强）、Flux.1 Dev（开源-非商用）、Flux.1 Schnell（开源-商用，Apache 2.0，蒸馏版，少步采样） |
| **计费方式** | Schnell：免费（自部署）；Dev：免费（自部署，仅研究）；Pro API：约 $0.050/张；第三方（Replicate/Fal.ai）约 $0.003-0.005/张 |
| **最大分辨率** | 原生 1024x1024，支持 upscale 至 4K |
| **突出能力** | 文字渲染能力在开源模型中最强，接近 DALL-E 3/Ideogram；人体结构准确度（尤其是手部）显著优于 SD3；提示词遵循优秀；美感接近 Midjourney |
| **优势** | 开源 + 文字渲染双强；基于 SD 的社区工具（ComfyUI、LoRA 训练）几乎无缝适配；Pro 版 API 质量媲美 Midjourney；架构简洁高效 |
| **劣势** | Dev 版有商业限制，用户困惑；模型体量大（12B 参数），本地部署 GPU 门槛高（建议 24GB+ VRAM）；生成速度较慢 |
| **适用场景** | 需要精准文字渲染的商业设计；自部署 + 高质量出图需求；开源社区开发基础模型 |

## 4. 国外生视频模型

### 4.1 OpenAI — Sora / Sora 2

| 属性 | 详情 |
|------|------|

#### 6.2.1 Stable Diffusion 3.5 (Stability AI)

## 11. 2026年趋势

### 11.1 2026 H1 关键趋势总结

| 趋势 | 说明 | 代表性事件 |
|------|------|-----------|
| **架构收敛至 DiT** | 几乎所有新模型（闭源和开源）均采用 Diffusion Transformer (DiT) 架构，UNet 架构基本退出主流 | Sora、Veo、Kling、Flux、Wan、Seedance 全部基于 DiT |
| **Flow Matching 成为标准** | 从噪声预测转向 Flow Matching / Rectified Flow，显著提升采样效率和质量 | Flux、SD3.5、Wan 2.6 均使用 Flow Matching |
| **开源加速追赶闭源** | 开源模型与闭源模型的质量差距从 2024 年的 1-2 年缩短至 2026 年的 3-6 个月 | Wan 2.6 接近 Veo 2 水平；Flux.1 接近 Midjourney V6 |
| **音视频统一生成** | 视频模型开始集成音频生成能力，实现视听一体输出 | Veo 3+、MOVA、Sora 2 部分支持 |
| **长视频突破** | 从 2024 年的 5-10 秒主流，2026 年 60-180 秒成为可能 | Veo 3.1 (180s)、Sora 2 (120s)、Kling 2 (120s+) |
| **实时生成逼近** | 部分模型实现近实时或交互式生成，为实时应用铺路 | SDXL Turbo、Flux Schnell、LTX Video 2.3（4s 出视频） |
| **中国模型集体崛起** | 国内模型在中文理解和性价比方面全面领先，在通用质量上也快速接近国际一线 | Kling 2、即梦、Vidu、Wan 2.6 |
| **文字渲染专项竞赛** | 文字渲染从"附赠功能"变为核心竞争维度，多模型将文字准确性作为主要卖点 | Ideogram 3.0 vs DALL-E 4 正面竞争 |
| **成本持续下降** | API 单张/单秒成本年降 30-50%，自部署硬件门槛降低 | 3 年前一张图 $0.10+，现在 $0.003-0.02 |
| **3D 生成实用化** | 3D 生成从研究走向生产，Mesh/纹理质量达到可用标准 | TripoSR 2、Meshy 3、Luma Genie |

### 11.2 架构演化路径

```
2022: Diffusion (DDPM, DDIM, 等)
  |
2023: Latent Diffusion (SD/SDXL) + UNet
  |
2024: DiT (Diffusion Transformer) 初现 + 3D VAE
  |     Sora 验证 DiT 在视频上的可行性
  |
2025: DiT + Flow Matching 成为主流
  |     Flux, SD3.5, Kling, Veo 全面转向
  |
2026: DiT + Flow Matching + 统一多模态架构
       T2I/T2V/I2V/音频统一为单一 DiT 架构
       Wan 2.6, Veo 3.1, Sora 2 均为 DiT 变体
```

### 11.3 开放 vs 闭源格局展望

| 维度 | 2024 年 | 2026 年现状 | 2026H2-2027 预测 |
|------|--------|------------|-----------------|
| **T2I 质量差距** | 闭源领先 1-2 年 | 开源差距缩至 3-6 月 | 开源有望在某些维度追平 |
| **T2V 质量差距** | 闭源绝对优势 | 开源差距约 6-12 月 | Wan/CogVideoX 迭代有望缩小 |
| **开源生态** | SD 主导 | Flux + Wan + CogVideoX 三足鼎立 | 更多中国开源模型进入国际视野 |
| **商业化** | 开源以研究为主 | Schnell/Wan 2.6 等可商用开源模型增多 | 开源+商业 API 双轨制成熟 |
| **社区工具** | ComfyUI 起步 | ComfyUI 成为事实标准，全模型支持 | 一体化低代码 AI 生图生视频平台出现 |

### 11.4 2026 下半年前瞻

- **音画同步生成（AV Generation）**：预计 Veo 4 / Sora 3 将原生支持高质量同步音频，不再依赖后期配音
- **交互式实时视频生成**：LTX 系列已验证低延迟可行性，预计年底出现可交互式视频生成产品
- **可控性与可编辑性深化**：从"生成一段视频"到"精确控制视频中每一帧的每一个元素"
- **端侧推理**：模型蒸馏和量化技术持续进步，部分中小型视频生成模型有望在手机/平板端运行
- **合规与版权框架建立**：随着 AI 生成内容充斥互联网，各国将加快 AI 内容标识和版权立法
- **中国模型国际化**：Kling、即梦、Vidu 等将加速海外市场拓展，与 Runway/Pika 正面竞争

## 附录 B：术语对照

| 英文术语 | 中文 | 说明 |
|----------|------|------|
| DiT (Diffusion Transformer) | 扩散变换器 | 当前主流生成模型架构，将传统 UNet 替换为 Transformer |
| Flow Matching | 流匹配 | 新一代扩散范式，直接预测信号流动路径，代替传统噪声预测 |
| 3D VAE | 三维变分自编码器 | 将视频压缩到时空隐空间，是视频生成的关键组件 |
| LoRA (Low-Rank Adaptation) | 低秩适配 | 轻量级模型微调技术，用极少参数实现特定风格/主体定制 |
| ControlNet | 控制网络 | 为扩散模型增加精确的构图/姿态/深度等控制能力 |
| Prompt Following | 提示词遵循 | 模型按照文本描述准确生成对应内容的程度 |
| Temporal Consistency | 时间一致性 | 视频中各帧之间的主体、光影、运动是否连贯不闪烁 |
| VRAM | 显存 | GPU 内存，决定了能运行多大参数的模型 |
| IP-Adapter | 图像提示适配器 | 允许用图片作为提示来引导生成（图生图的一种方式） |
| FPS | 帧每秒 | 视频流畅度指标，24/30fps 为常见标准 |

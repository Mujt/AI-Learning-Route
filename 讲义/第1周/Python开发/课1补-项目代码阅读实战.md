## 一、读项目方法论（15 分钟）

### 1.1 核心心法：像读书一样读代码

```
读书：先看目录 → 再看章节 → 最后精读句子
读代码：先看结构 → 再找入口 → 跟随调用链 → 理解数据流
```

### 1.2 读项目四步法（本课主线）

```
第1步 看结构：浏览项目文件夹和文件，画出"地图"
第2步 找入口：找到 main.py / app.py / 入口函数（程序从哪里开始跑）
第3步 跟调用链：从入口出发，跟着函数调用/类方法一路读下去
第4步 画脑图：用文字/画图梳理"数据从哪来 → 怎么处理 → 到哪去"
```

> **记住**：**不要从头到尾逐行读**！那会迷失。先整体后局部，先结构后细节。

### 1.3 AI 辅助阅读法（最高效的组合拳）

```
提问模板1（整体理解）：
"请帮我分析这个 Python 项目的结构和功能：
1. 项目是干什么的？
2. 有哪些文件和目录，各自的作用是什么？
3. 程序的入口是哪个文件/函数？
[粘贴项目结构 或 关键文件路径]"

提问模板2（逐段精读）：
"下面这段代码在做什么？请逐行用大白话解释，并指出用到了哪些Python知识点：
[粘贴代码]"

提问模板3（语法查询）：
"Python 中 [语法/库] 是什么意思？请举例说明"
```

> **黄金组合**：`AI 辅助 + 自己思考 = 真读懂`。AI 负责"翻译"，你负责"理解与验证"——运行代码看输出，修改参数看变化。

### 1.4 读懂项目的必备背景：requirements.txt 与虚拟环境

```python
# requirements.txt：列出项目依赖（读项目第一步看它）
# 内容示例：
requests==2.32.0
flask==3.0.0
pandas==2.2.0
openai==1.30.0
```

```bash
pip install -r requirements.txt   # 一键安装所有依赖
```

> **读懂意义**：看到 `==` 表示固定版本，`>=` 表示最低版本。**拿到一个陌生项目，先看 `requirements.txt` 就知道项目用了哪些库**——这决定了"项目是做什么的"。

### 2.1 后端 Web 项目的典型结构

```
my_web_app/
├── requirements.txt        # 依赖清单
├── app.py                  # 入口文件（Flask 风格）
├── config.py               # 配置（数据库地址、密钥等）
├── models.py               # 数据模型（类，对应数据库表）
├── routes/                 # 路由（URL 处理函数）
│   ├── __init__.py
│   ├── user_routes.py      # /user 相关接口
│   └── book_routes.py      # /book 相关接口
├── services/               # 业务逻辑（调模型的层）
│   └── user_service.py
└── utils/                  # 工具函数
    ├── __init__.py
    └── auth.py             # 认证工具
```

### 2.2 Agent 项目的典型结构

```
my_agent/
├── requirements.txt        # openai / langchain 等
├── main.py                 # 入口：启动 Agent 交互
├── config.py               # API 密钥、模型名
├── agent.py                # Agent 主类（继承 BaseAgent）
├── tools/                  # 工具目录
│   ├── __init__.py
│   ├── web_search.py       # 搜索工具（@tool）
│   ├── calculator.py       # 计算工具
│   └── database.py         # 查库工具
└── memory.py               # 记忆管理（类）
```

> **练习**：看到上面的结构，用四步法说出："入口是 `main.py`，配置在 `config.py`，业务逻辑在 `services/` 或 `agent.py`，工具在 `tools/`。"

## 三、精读实战①：一个 Web 后端项目（30 分钟）

> 下面是一个 Flask 风格的后端项目（简化但结构真实）。请先独立通读，再对照讲解。

```python
# ============ config.py：配置 ============
API_VERSION = "v1"
DATABASE_URL = "sqlite:///books.db"
SECRET_KEY = "please-change-me"

# ============ models.py：数据模型（类！） ============
class Book:
    """图书模型：对应数据库中的 books 表"""

    def __init__(self, book_id, title, author, price):
        self.book_id = book_id
        self.title = title
        self.author = author
        self.price = price

    def to_dict(self):
        """转成字典：方便返回给前端（JSON 格式）"""
        return {
            "id": self.book_id,
            "title": self.title,
            "author": self.author,
            "price": self.price,
        }

# ============ services/book_service.py：业务逻辑 ============
class BookService:
    """图书业务层：真正的逻辑在这里"""

    def __init__(self):
        # 用字典模拟数据库（真实项目用 SQL 数据库）
        self._books = {
            1: Book(1, "Python编程", "张三", 59.9),
            2: Book(2, "AI入门", "李四", 49.9),
        }

    def get_all(self):
        """返回所有图书"""
        return [b.to_dict() for b in self._books.values()]

    def get_by_id(self, book_id):
        """按 ID 查询，找不到返回 None"""
        return self._books.get(book_id)

# ============ app.py：入口（Web 框架核心） ============
from flask import Flask, jsonify, request

app = Flask(__name__)            # 创建 Flask 应用（框架的类！）
service = BookService()          # 实例化业务层（组合关系）

@app.route("/api/books", methods=["GET"])
def list_books():
    """GET /api/books → 返回所有图书"""
    books = service.get_all()
    return jsonify(books)

@app.route("/api/books/<int:book_id>", methods=["GET"])
def get_book(book_id):
    """GET /api/books/1 → 返回ID为1的图书"""
    book = service.get_by_id(book_id)
    if book is None:
        return jsonify({"error": "图书不存在"}), 404
    return jsonify(book.to_dict())

@app.route("/api/books", methods=["POST"])
def create_book():
    """POST /api/books → 新建图书"""
    data = request.get_json()    # 前端传来的 JSON
    new_book = Book(3, data["title"], data["author"], data["price"])
    service._books[3] = new_book
    return jsonify(new_book.to_dict()), 201

if __name__ == "__main__":
    app.run(debug=True)
```

### 3.1 教师精读演示（按四步法）

**第1步 看结构**：
- `config.py`：配置（URL、密钥）→ 眼睛扫过即可，不深究
- `models.py`：数据模型类 → 一个类对应一种"业务对象"
- `services/`：业务逻辑 → 核心
- `app.py`：入口 → 从这里开始读！

**第2步 找入口**：`app.py` 的 `if __name__ == "__main__":` → Flask 应用启动。

**第3步 跟调用链**（以"查看所有图书"为例）：

```
浏览器访问 GET /api/books
   ↓
@app.route("/api/books") 装饰器把 list_books 函数绑定到 URL
   ↓
list_books() 被调用
   ↓
service.get_all()  →  BookService 类的实例方法
   ↓
[b.to_dict() for b in self._books.values()]  （列表推导式 + 类方法）
   ↓
jsonify(...) 把字典列表转成 JSON 返回给前端
```

**第4步 画脑图**：

```
前端(浏览器)  →  HTTP请求  →  Flask路由(app.py)  →  BookService
                                                       ↓
   前端拿到JSON  ←  jsonify  ←  Book.to_dict()  ←   Book数据
```

### 3.2 读代码时遇到的语法复习

| 代码 | 知识点 | 课1 哪学的 |
|------|--------|--------------|
| `class Book:` / `__init__` / `self` | 类与对象 | 课1 |
| `@app.route(...)` | 装饰器 | 课1 |
| `[b.to_dict() for b in ...]` | 列表推导式 | 课1 |
| `service.get_all()` | 组合：类里用另一个类 | 课1 |
| `if __name__ == "__main__":` | 模块入口判断 | 课1（见下方补充） |

**`if __name__ == "__main__":` 是什么？**（项目入口的标志）

```python
# 当直接运行这个文件时，__name__ == "__main__"
# 当被 import 时，__name__ == 模块名 → 下面代码不执行
if __name__ == "__main__":
    print("只有直接运行时才执行我")
```

> **读懂意义**：这是 Python 项目入口文件的"标准开头"。**看到它就找到程序入口了**——这是读任何项目的第 2 步。

## 四、精读实战②：一个 Agent 项目（30 分钟）

> 下面是 Agent 项目的核心代码（简化但结构真实）。Agent 的核心思想：**循环接收任务 → 思考 → 调用工具 → 返回结果**。

```python
# ============ config.py：配置 ============
OPENAI_API_KEY = "sk-xxxx"      # 真实项目从环境变量读取，别硬编码！
MODEL_NAME = "gpt-4o-mini"

# ============ tools/ 工具目录 ============
# tools/calculator.py：一个工具（Agent 的能力）
from crewai.tools import tool

@tool
def calculate(expression: str) -> str:
    """计算数学表达式，如 '3 + 5 * 2'"""
    try:
        result = eval(expression)      # 注意：eval 不安全，教学用；真实项目用安全的解析库
        return f"计算结果：{result}"
    except Exception as e:
        return f"计算失败：{e}"

# ============ agent.py：Agent 主类 ============
from config import MODEL_NAME, OPENAI_API_KEY

class SimpleAgent:
    """简单 Agent：具备"调用工具 + 调用大模型"的能力"""

    def __init__(self, name, model=MODEL_NAME, tools=None):
        self.name = name
        self.model = model
        self.tools = tools if tools else []   # 工具列表：每个元素是函数

    def _find_tool(self, tool_name):
        """根据名字找到工具函数"""
        for tool_func in self.tools:
            if tool_func.__name__ == tool_name:
                return tool_func
        return None

    def run(self, task):
        """执行任务：模拟"思考→调用工具→得出结论"的循环"""
        print(f"[{self.name}] 收到任务：{task}")

        # 第1步：判断任务是否需要工具（真实项目这里调用 LLM 判断）
        if "计算" in task or "多少" in task:
            # 第2步：从任务中提取表达式（简化：模拟 LLM 提取）
            expression = task.replace("计算", "").replace("等于多少", "").strip()

            # 第3步：调用工具
            calc_tool = self._find_tool("calculate")
            result = calc_tool(expression)
            print(f"[{self.name}] 工具返回：{result}")
            return result
        else:
            # 第4步：不需要工具 → 直接调用大模型回答（简化模拟）
            print(f"[{self.name}] 调用大模型 {self.model} ...")
            return f"[模拟回复] 关于'{task}'，这是一个通用回答"

# ============ main.py：入口 ============
from agent import SimpleAgent
from tools.calculator import calculate

def main():
    # 创建 Agent，注册工具
    agent = SimpleAgent(
        name="小助手",
        tools=[calculate],        # 把工具函数注册给 Agent
    )

    # 交互循环：Agent 的核心形态
    while True:
        task = input("请输入任务（输入 exit 退出）：")
        if task.lower() == "exit":
            break
        result = agent.run(task)   # 调用 Agent 执行任务
        print(f"回答：{result}")

if __name__ == "__main__":
    main()
```

### 4.1 教师精读演示

**第1步 看结构**：`config.py`（配置）→ `tools/`（Agent 的能力清单）→ `agent.py`（核心逻辑）→ `main.py`（入口）。

**第2步 找入口**：`main.py` 的 `main()` → `while True` 交互循环。

**第3步 跟调用链**（以"计算 3+5 等于多少"为例）：

```
用户输入 "计算 3+5 等于多少"
   ↓
main() → agent.run(task)
   ↓
SimpleAgent.run()：判断任务包含"计算"
   ↓
提取表达式 → _find_tool("calculate") 找到工具
   ↓
调用 calculate("3+5") → 返回 "计算结果：8"
   ↓
打印回答
```

**第4步 画脑图**：

```
用户输入 → main.py(交互循环) → agent.run(任务)
                                    ↓ 需要工具？
                                    ↓ 是           否
                              _find_tool → 调用工具 → 结果
                                                      ↓
                                         直接调用大模型
                                                      ↓
                                               返回回答 → 打印
```

### 4.2 本课最重要的三个"读懂点"

1. **`@tool` 装饰器**（课1 讲过）：把普通函数变成"Agent 能调用的工具"——这是 Agent 框架（CrewAI/LangChain）的标准写法。
2. **`self.tools = tools if tools else []`**：默认参数 + 三目表达式——"如果传了 tools 就用，没传就空列表"。
3. **`while True` 交互循环**：Agent 项目的入口形态——"不停接收任务，直到用户说退出"。

### 4.3 思考题

1. 如果把 `SimpleAgent` 的 `_find_tool` 改成"按序号找工具"，需要改哪里？——把 `tool_func.__name__` 改成比较索引。
2. 真实的 Agent（如 LangChain Agent）比这个复杂在哪里？——真实项目：LLM 负责"判断用哪个工具、传什么参数"，工具调用结果再喂回 LLM 循环（ReAct 模式）。**但骨架就是你看到的这套**：任务 → 思考 → 工具 → 结果 → 循环。

> **教学提示**：向学生强调——"Agent 不是黑魔法，就是'循环 + 工具函数 + 大模型调用'的组合。你能读懂这段代码，就已经能读懂 70% 的 Agent 项目。"

### 5.1 任务：读懂"数据分析小助手"项目

```python
# ============ data_utils.py ============
import pandas as pd

def load_data(filepath):
    """读取 CSV 文件"""
    return pd.read_csv(filepath, encoding="utf-8-sig")

def top_sales(df, n=3):
    """返回销售额最高的前 n 个地区"""
    by_region = df.groupby("地区")["销售额"].sum()
    return by_region.sort_values(ascending=False).head(n)

# ============ report.py ============
import matplotlib.pyplot as plt

def make_chart(series, title):
    """根据 Series 画柱状图"""
    plt.rcParams["font.sans-serif"] = ["SimHei", "Microsoft YaHei"]
    plt.rcParams["axes.unicode_minus"] = False
    series.plot(kind="bar")
    plt.title(title)
    plt.savefig(f"{title}.png", dpi=150)
    print(f"图表已保存：{title}.png")

# ============ main.py ============
from data_utils import load_data, top_sales
from report import make_chart

def main():
    df = load_data("sales.csv")          # 1. 读数据
    top = top_sales(df)                   # 2. 分析
    print("Top 3 地区：")
    print(top)
    make_chart(top, "各地区销售额Top3")   # 3. 出图

if __name__ == "__main__":
    main()
```

## 八、FAQ

**Q1：我还是觉得自己写不出代码，是不是没学会？**
本课程目标本来就是"读懂"不是"熟练写"。你能读懂项目、能借助 AI 写出小程序，就已经达到目标。写代码能力可以在后续课程（第3-5周）和实践中逐步提高。

**Q2：读项目时文件太多，从哪里开始？**
永远从 `requirements.txt` + `main.py`（或 `app.py`/`README.md`）开始。README 会告诉你是干什么的，requirements 告诉你了哪些库，main 是入口。

**Q3：读项目时遇到看不懂的库怎么办？**
三步：先看 import 语句认识库名 → 问 AI"这个库是干什么的" → 看它的调用方式（大部分库用法固定）。**不需要理解库的内部实现，只需要知道"它能做什么、怎么调"**。

**Q4：`if __name__ == "__main__":` 每次都看不懂？**
记住一句话：**"直接运行这个文件时才执行里面的代码，被 import 时不执行"**。看到它 = 找到入口。

**Q5：我读代码的速度很慢怎么办？**
正常！读代码比写代码慢是普遍现象。先用 AI 快速建立整体理解，再挑关键段落精读。**速度来自"读得多 + 会跳读"，不来自更努力地逐行啃**。

**Q6：什么才算"读懂"了一个项目？**
能回答四个问题：(1) 它是干什么的？(2) 数据从哪来、到哪去？(3) 核心逻辑在哪个文件哪个函数？(4) 如果让我改一个小功能，我知道改哪里。**能回答这四点，就算读懂了**。

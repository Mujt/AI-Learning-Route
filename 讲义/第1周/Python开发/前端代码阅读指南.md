# 前端代码阅读指南：HTML / CSS / JavaScript 速览

> **定位**：本课程目标之一是"读懂绝大多数 Python 项目代码"，而大量 Python 项目是**前后端项目**——后端 Python（Flask/FastAPI/Django），前端 **HTML + CSS + JavaScript**。本指南是阅读这类项目前端代码的补充材料，与《课1》6.7 节、《课1补-项目代码阅读实战.md》的前后端精读配套。
> **目标**：不要求会写，只要求**看到前端代码能认出它在干什么、知道去哪改**——和学 Python 的目标一致。
> **核心心法**：前端三件套各管一摊——**HTML 是骨架（内容），CSS 是皮肤（长相），JavaScript 是大脑（行为）**。

---

## 一、前端三件套的分工

```
浏览器（用户看到的界面）        服务器（Python 跑的地方）
┌─────────────────────┐        ┌─────────────────────┐
│  HTML  内容/结构      │  HTTP  │  Flask / FastAPI    │
│  CSS   样式/长相      │ ─────► │  路由、业务逻辑      │
│  JS    交互/行为      │  JSON  │  数据库、模型        │
└─────────────────────┘ ◄───── └─────────────────────┘
```

| 语言 | 角色 | 比喻 | 回答的问题 |
|------|------|------|-----------|
| HTML | 结构 | 骨架 | 页面上**有什么** |
| CSS | 样式 | 皮肤/衣服 | 页面**长什么样** |
| JavaScript | 行为 | 大脑 | 页面**点一下会怎样** |

> **读代码第一步**：看到 `.html` / `.css` / `.js` / `.vue` / `.jsx` 结尾的文件就进入前端地盘。先问自己：这段是 HTML（尖括号 `<...>` 标签）？CSS（`选择器 { 属性: 值 }`）？还是 JS（`let/function/=>`）？**认对语言，读懂就成功一半。**

## 二、HTML：网页的骨架

语法极简单：**用"尖括号标签"把内容包起来**，标签成对出现。

### 2.1 标准文件长相

```html
<!DOCTYPE html>                 <!-- 声明：HTML5 文档，每页开头都有 -->
<html>
<head>
    <meta charset="UTF-8">      <!-- 编码，防中文乱码 -->
    <title>页面标题</title>      <!-- 浏览器标签页显示的名字 -->
    <link rel="stylesheet" href="style.css">   <!-- 引入外部 CSS -->
</head>
<body>
    <!-- 看得见的内容都在 body 里 -->
    <h1>我是一级标题</h1>
    <p>我是一个段落。</p>
</body>
</html>
```

> `<head>` 放设置信息（不显示），`<body>` 放看得见的内容；`<!-- -->` 是注释。

### 2.2 高频标签（读页面结构的"词汇表"）

```html
<h1>~<h6> 标题（h1 最大）       <p> 段落
<a href="网址">链接</a>          <img src="图片地址" alt="描述">
<ul><li>无序列表</li></ul>       <ol><li>有序列表</li></ol>
<div> 块级容器（占一整行）        <span> 行内容器（不换行）
<input type="text" placeholder="提示">   <!-- 输入框 -->
<button onclick="fn()">按钮</button>     <!-- 按钮，onclick=点击后调用的 JS 函数 -->
```

### 2.3 最关键的属性：`id` 和 `class`

```html
<input id="name" class="input-box" placeholder="姓名">
```

| 属性 | 作用 | 比喻 | 谁用它 |
|------|------|------|--------|
| `id` | 唯一标识（全页不重复） | 身份证号 | **JS 用它精确找元素**（`getElementById`） |
| `class` | 分类标签（可复用） | 班级/标签 | **CSS 用它批量上样式**（`.class名`） |

> **关键**：`id` 给 JS 用，`class` 给 CSS 用。看到 `<div id="app">` 就知道 JS 后面会操作它；看到 `class="btn"` 就知道 CSS 里有 `.btn` 的样式。

## 三、CSS：网页的皮肤

语法：**`选择器 { 属性: 值; }`**——"选中谁 → 改成什么样"。

### 3.1 选择器：CSS 怎么"选中"元素

```css
p { color: red; }              /* ① 标签选择器：所有 <p> */
.btn { background: blue; }     /* ② class 选择器（点开头）：class="btn" 的 */
#app { width: 600px; }         /* ③ id 选择器（# 开头）：id="app" 的 */
.card p { font-size: 14px; }   /* ④ 后代选择器（空格）：.card 里面的 p */
.btn:hover { color: white; }   /* ⑤ 伪类：鼠标悬停时 */
```

### 3.2 常用样式属性

```css
.box {
    width: 200px;        /* 宽 */
    height: 100px;       /* 高 */
    margin: 10px;        /* 外边距：和外面元素的距离 */
    padding: 15px;       /* 内边距：内容和边框的距离 */
    border: 1px solid #ccc;  /* 边框：粗细 样式 颜色 */
    background: #f0f0f0; /* 背景色（#十六进制） */
    color: #333;         /* 文字颜色 */
    font-size: 16px;     /* 字号 */
    text-align: center;  /* 文字居中 */
}
```

**盒子模型**：`margin`（盒子外）→ `border`（边框）→ `padding`（内边距）→ 内容。**一句话：`margin` 管"离别人多远"，`padding` 管"内容离自己边框多远"。**

### 3.3 Flex 布局：现代页面的"排版神器"

```css
.container {
    display: flex;            /* 开启 flex：子元素横向排成一行 */
    justify-content: center;  /* 水平居中（flex-start/flex-end/space-between） */
    align-items: center;      /* 垂直居中 */
    gap: 20px;                /* 子元素间距 */
}
```

> 看到 `display: flex` + `justify-content` + `align-items`，翻译成"把子元素横向排开、水平垂直都居中"。**这是几乎所有网页"居中排布"的标准写法。**

## 四、JavaScript：网页的大脑

JS 语法和 Python 很像，但有几处关键区别。

### 4.1 变量与类型

```javascript
let age = 20;              // 变量（相当于 Python 的 age = 20）
const name = "张三";        // 常量：赋值后不能改
var old = 1;               // 老写法，少用

let arr = [1, 2, 3];                        // 数组 = Python 的列表
let person = { name: "张三", age: 20 };      // 对象 = Python 的字典！
console.log(person.name);                    // 取字段（console.log = print）
```

> **关键认知**：JS 对象 `{ key: value }` 就是 Python 字典，JS 数组 `[]` 就是 Python 列表。`console.log()` = `print()`。

### 4.2 函数：`function` 和箭头函数 `=>`

```javascript
function add(a, b) { return a + b; }     // 传统函数

const add2 = (a, b) => a + b;            // 箭头函数：现代前端极常见
const greet = (name) => { return "你好" + name; };
```

> 看到 `(参数) => 结果` 就认识：**这是一个函数**，类似 Python 的 `lambda`，但无处不在。

### 4.3 DOM 操作：JS 怎么"找到并改动"页面

```javascript
let nameInput = document.getElementById("name");   // 找到 id="name" 的元素
let buttons = document.querySelectorAll(".btn");   // 找到所有 class="btn"

let val = nameInput.value;               // 读取输入框里的文字（最常用！）
nameInput.value = "新内容";              // 改输入框内容
document.getElementById("result").innerHTML = "<b>加粗</b>";  // 塞 HTML 进去
```

> `getElementById("xxx")` / `querySelector(".xxx")` 是"寻人启事"，`.value` 是"取输入框的值"。**这套就是"从页面拿数据、把数据放回页面"的标准动作。**

### 4.4 事件：让页面"响应"操作

```javascript
document.getElementById("btn").addEventListener("click", () => {
    alert("你点了我！");       // 弹窗
});
```

| 事件名 | 何时触发 |
|--------|----------|
| `click` | 鼠标点击 |
| `input` | 输入框内容变化 |
| `submit` | 表单提交 |

> 看到 `addEventListener("click", ...)` 就翻译成"**当用户点击时，执行箭头函数里的代码**"。所有前端交互都是"事件 + 回调函数"模式。

### 4.5 ES6 高频语法：模板字符串、解构、数组方法

```javascript
// ① 模板字符串（反引号 ` ）：相当于 Python 的 f-string
console.log(`你好，${name}`);       // 注意是反引号，不是单引号

// ② 解构赋值：一次取多个
let { title, price } = book;        // 相当于 title = book.title; price = book.price

// ③ 数组方法（Python 列表推导式的"JS 版"）
let passed = nums.filter(n => n >= 60);        // 筛选（等价 [n for n in nums if n>=60]）
let names = users.map(u => u.name);            // 映射：取每个元素的 name
users.forEach(u => console.log(u.name));       // 遍历
```

> 这三样在 Vue/React 项目里**到处都是**：`${}` 插值、`=>` 函数、`.map/.filter` 数据处理。

## 五、前后端如何"对话"：fetch 与 axios

### 5.1 用 `fetch` 请求后端（浏览器自带）

```javascript
async function send() {
    // ① 从输入框取数据，拼成对象
    let data = {
        name: document.getElementById("name").value,
        score: Number(document.getElementById("score").value)   // Number() 转数字
    };

    // ② fetch 发请求
    let res = await fetch("/student", {
        method: "POST",                                    // GET 要数据 / POST 交数据
        headers: { "Content-Type": "application/json" },   // 声明：我发的是 JSON
        body: JSON.stringify(data)                         // JS 对象 → JSON 字符串
    });

    // ③ 拿后端返回
    let result = await res.json();     // JSON 字符串 → JS 对象
    console.log(result.msg);
}
```

**读代码要点**：
- `fetch(url, {...})` = "发 HTTP 请求"；`method`：`GET` 要数据、`POST` 交数据（`PUT` 改、`DELETE` 删）。
- `JSON.stringify(obj)` = JS 对象 → JSON 字符串（**发出去前**）；`res.json()` = JSON 字符串 → JS 对象（**收到后**）。
- `await` = "停一下，等这个异步操作完成"。

> **关键认知**：这一节和《课1》6.7 节是同一件事——前端 `fetch` 发 JSON → 后端 FastAPI 收 JSON、算、回 JSON → 前端 `res.json()` 再转回来。**前后端都在"发 JSON、收 JSON"，只是语言不同。**

### 5.2 `async` / `await`：JS 的"等一等"

```javascript
async function getBooks() {
    let res = await fetch("/api/books");   // await：停在这等结果
    let books = await res.json();
    return books;
}
```

> 看到 `async function` + `await`，翻译成"这个函数里有'要等网络'的操作，await 就是'停一下等它干完'"。`.then()` 是同一件事的老写法。

### 5.3 `axios`：最流行的请求库（Vue/React 项目必见）

```javascript
import axios from "axios";

let res = await axios.get("/api/books");              // 比 fetch 简洁
let res2 = await axios.post("/api/books", { title: "新书", price: 59.9 });  // 自动转 JSON
console.log(res.data);           // axios 把返回数据放在 .data 里（不是 .json()！）
```

> `axios.get(url)` / `axios.post(url, data)`，结果在 **`res.data`**。功能与 `fetch` 一样，写法更省事。

## 六、认识前端框架：Vue 与 React

**大量真实项目用框架而非手写三件套**。看到下面特征就知道进了框架代码——但底层还是前面那三件套。

### 6.1 Vue（`.vue` 文件，中文生态最常见）

```vue
<template>
    <!-- ① 模板 = HTML，负责"长什么样" -->
    <div>
        <input v-model="name" placeholder="姓名">      <!-- v-model：输入框和变量双向绑定 -->
        <button @click="sayHi">打招呼</button>          <!-- @click：点击事件 -->
        <p v-if="name">你好，{{ name }}</p>            <!-- v-if 条件显示；{{ }} 插值 -->
        <li v-for="book in books" :key="book.id">      <!-- v-for 循环渲染 -->
            {{ book.title }}
        </li>
    </div>
</template>

<script setup>
import { ref } from "vue";
const name = ref("");                 // ref()：定义响应式变量（值变了页面自动变）
const books = ref([{ id: 1, title: "Python编程" }]);
function sayHi() { alert("你好，" + name.value); }   // JS 里写 name.value，模板里写 name
</script>

<style scoped>  /* ② 样式 = CSS，scoped 只作用于当前组件 */
p { color: blue; }
</style>
```

**Vue 阅读要点**：
- `.vue` 文件 = 一个组件，三块：`<template>`（HTML）+ `<script>`（JS）+ `<style>`（CSS）。
- `{{ }}` 插值；`v-model` 双向绑定；`v-if` / `v-for` 条件/循环渲染；`@click` 事件。
- `ref()` 包裹的变量 = "响应式"（值一变页面自动刷新）——框架最核心的魔法。

### 6.2 React（`.jsx` / `.tsx`）

```jsx
import { useState } from "react";

function BookList() {
    const [books, setBooks] = useState([{ id: 1, title: "Python编程" }]);  // 状态
    const [name, setName] = useState("");

    return (                                   // return 括号里就是"页面"（JSX）
        <div>
            <input value={name} onChange={e => setName(e.target.value)} />
            {/* onChange 输入变化事件；e.target.value 取输入框的值 */}
            <button onClick={() => alert("你好，" + name)}>打招呼</button>
            <ul>
                {books.map(book => (           // 用 map 循环渲染列表
                    <li key={book.id}>{book.title}</li>
                ))}
            </ul>
        </div>
    );
}
```

**React 阅读要点**：
- **JSX**：HTML 直接写在 JS 里（`return` 后面）。看到 `.jsx` 的 `return (<div>...</div>)` 就是"组件的页面部分"。
- `{ }` 单花括号 = 嵌入 JS 表达式（对应 Vue 的 `{{ }}`）；`.map()` 循环渲染（对应 `v-for`）。
- `useState()` = 定义状态，返回 `[值, 改值函数]`；`onClick` / `onChange` 是事件。

> **读框架心法**：框架只是把 HTML/CSS/JS 重新打包了——认识的三件套一个不少，只是换了写法。**看到 `.vue`/`.jsx`，先找 `template`/`return`（页面），再找 `script`/函数（逻辑）。**

## 七、读前端代码的方法 + AI 辅助

### 7.1 前端版"四步法"（呼应课3）

```
第1步 看结构：先读 HTML（template/return）——页面上有哪些元素？
第2步 看样式：扫一眼 CSS——大概长什么样（布局靠 flex，颜色看 background/color）
第3步 看行为：找 JS 里的 addEventListener/@click/onClick——点了会怎样？
第4步 看数据：找 fetch/axios——数据从哪个接口来、发什么、收到后放哪？
```

### 7.2 最强工具：浏览器 F12 开发者工具

- 按 **F12** → `Elements`（元素）看 HTML/CSS，`Console`（控制台）看 `console.log` 输出和报错，`Network`（网络）看发了哪些请求、接口返回什么 JSON。
- **这是读前端项目的"运行验证"，相当于 Python 里运行代码看输出。**

### 7.3 AI 辅助阅读模板

```
提问模板1（整体理解）：
"这是一个前端页面，请帮我分析：
1. 页面上有哪些元素？整体结构是什么？
2. 样式上用了什么布局？
3. 有哪些交互（点击/输入会触发什么）？
4. 它调用了哪些后端接口？[粘贴 HTML/JS 代码]"

提问模板2（逐段精读）：
"下面这段前端代码在做什么？请逐行用大白话解释，并指出用了哪些
HTML/CSS/JS 知识点：[粘贴代码]"
```

> **黄金组合**：`AI 翻译 + 自己 F12 验证 = 真读懂`。前端代码比后端更"看得见摸得着"——改个颜色、点个按钮，立刻能看到效果。

## 九、FAQ

**Q1：我 Python 还没完全会，再学前端会不会太杂？**
不会。本指南目标是"**认出前端代码**"，不是"写前端"。前后端项目里，后端你已经会读（Python），前端只需要"认出三件套在干嘛"就够了。而且前端代码更直观（能改能点能看效果）。

**Q2：Vue 和 React 到底学哪个？**
都不用学。本课程只要求"**看到能认出是框架代码、大概知道结构**"。具体框架语法，等你真正做前端项目时再深入。现在看到 `.vue` 认 Vue、`.jsx` 认 React 即可。

**Q3：遇到看不懂的前端代码怎么办？**
和 Python 一样的三步：① 先认语言（HTML/CSS/JS）；② 复制给 AI"用大白话解释这段前端代码"；③ 按 F12 在浏览器里点一点、改一改，看效果。

**Q4：`==` 和 `===` 有什么区别？**
JS 里 `==` 会自动转换类型（`"5" == 5` 为 true），`===` 严格相等（`"5" === 5` 为 false）。**现代代码几乎都用 `===`**，看到它翻译成"完全相等"。

**Q5：前端代码里到处都是 `$`、`{{ }}`、`=>`，完全看不懂？**
`$` 通常来自 jQuery（老库）或模板变量；`{{ }}` 是 Vue 插值；`=>` 是箭头函数。对照本文第八节速查卡，逐个认即可。**认符号是读前端的核心技巧，和认 Python 的 `@`、`[]` 一样。**

---

> **本指南结束。** 现在你已经能把"读 Python 项目"的视野扩展到前端：后端用四步法读 Python，前端用"看结构→看样式→看行为→看数据"读三件套，再配合 F12 和 AI，前后端项目都能完整读懂。

## 本课核心回顾（2分钟）

> "在大家收拾东西之前，我希望你们带走五句话。这五句话，是这节课最核心的东西。如果将来有人问你'AI课你学了什么'，你能说出这五句话，这节课就值了。"

### 第一句：AI的发展是一条70年的路，不是一夜之间冒出来的

> "1956年达特茅斯会议，四个年轻人立下宏愿。然后是两次AI寒冬——砸了无数人的饭碗，也熬走了无数投机者。直到Transformer架构出现、算力爆发、数据井喷，大模型才真正'活'了过来。
>
> **你要记住的：** 任何一个改变世界的技术，背后都是无数人几十年的坚持。今天你用ChatGPT几秒钟得到答案，是因为有人用了一辈子的时间，让这件事成为可能。"

### 第二句：ChatGPT的火爆，是技术突破、产品设计与时代机遇的完美结合

> "GPT不是第一个大模型，但它是第一个让普通人觉得'这东西跟我有关'的AI。为什么？因为技术（GPT架构的迭代成熟）、产品（对话界面，零学习成本）、时代（移动互联网让每个人都在线）——三个齿轮恰好咬合在一起。
>
> **你要记住的：** 技术本身不改变世界。技术+好产品+对的时间，才改变世界。"

### 第三句：大模型能做的事情远超你的想象——但你需要学会"指挥"它

> "我们刚才讲了十二项核心能力，从写文字到画图表，从查文献到推导公式。但说实话，这只是冰山一角。想象力的边界，才是AI能力的边界。
>
> **你要记住的：** AI就像一个全能的实习生——能力极强，但需要明确的指令。你给的指令越清晰，它给你的结果越惊艳。所以我们下节课要学的第一件事，就是怎么写好'指令'——也就是Prompt。"

### 第四句：AI是电动自行车，不是自动驾驶汽车——你掌握方向

> "我们在KB7讨论过这个问题。AI不会替代你的专业判断，不会替你承担责任，更不会帮你考注册工程师。但它能让你的效率翻倍、思路打开、作品更出彩。
>
> **你要记住的：** 坐在驾驶座上的是你。AI是电助力——你踩它才发力，你不踩它就是一辆普通的自行车。你越专业，AI越有用。反过来——如果你的专业底子不扎实，AI给你再好的回答，你也分辨不了对错。"

### 第五句：不要只用AI一种工具——组建你的"AI顾问团"

> "不同的模型各有千秋。有的擅长推理和逻辑分析，有的擅长长文写作，有的擅长代码生成，有的擅长创意构思。聪明的人不会只用一个AI——他们会根据任务类型，选择最合适的工具。
>
> **你要记住的：** 未来的核心竞争力不是'会不会用AI'——是'会不会用好几个AI交叉验证'。这就是为什么我们的第一个作业，就是让你对比不同的AI工具。"

### 💼 企业视角：五句话的商业翻译

> "💼 企业学员，把刚才的五句话翻译成商业语言——这五条，就是你们下周可以在公司内部会议上用的'AI战略速成版'："
>
> **1. AI是杠杆，不是行业。**
> "不要问'要不要做AI'，要问'AI怎么杠杆我的业务'。AI不会凭空创造一个新行业让你跳进去——它是在你现有业务上叠加效率倍增器。如果你的公司今天连数字化都没做好，先补数字化；如果已经数字化了，AI就是你的下一步。"
>
> **2. ChatGPT的五大成功原因 = 五条商业法则。**
> "技术突破（研发投入要有耐心）+ 产品设计（用户体验决定adoption率）+ 时代机遇（抓住窗口期，早了不行，晚了也不行）——三者缺一不可。你的企业引入AI也一样：选对工具（技术）、让员工愿意用（产品）、在行业还没全面卷起来之前先跑通（时机）。"
>
> **3. 大模型的能力边界 = 你的指令边界。**
> "企业引入AI的关键不是买最贵的模型——是培养团队'指挥AI的能力'。一个会写Prompt的团队，用免费模型也能产出高质量结果；一个不会用的团队，花再多钱也是摆设。Prompt Engineering不是技术岗位——是未来所有人的基础素养。"
>
> **4. AI是电动自行车，不是自动驾驶汽车——你掌握方向。**
> "企业负责方向、判断、责任；AI负责效率、广度、速度。公式：专业团队 + AI > 纯AI > 纯专业团队。这意味着：不是用AI替代人，而是用AI武装人。投资员工的专业能力 + 投资AI工具 = 最大化ROI。"
>
> **5. 不要只用一种AI——建立你的'多模型策略'。**
> "聪明的企业不会被任何一家AI供应商锁死。不同任务用不同工具，重要决策用多个AI交叉验证。2026年的AI格局变化极快——今天的领先者明天可能被超越。保持灵活性，不要把鸡蛋放在一个篮子里。"

## 关键概念闪电回顾（1分钟）

> "好了，五句话讲完了。现在我们来做一个小测试——**闪电回顾**。我说概念，你心里默念答案。如果你能脱口而出，说明你跟上了。如果卡住了——别担心，讲义后面有附录，回去翻一下。"

| 概念 | 提示（你可以大声说出来） |
|------|--------------------------|
| **图灵测试** | "1950年，谁提出来的？测试什么？" → 图灵。测试机器是否表现出与人类无法区分的智能行为。 |
| **Transformer** | "2017年Google发表的革命性架构，几乎所有现代大模型的基石，被比作AI界的'iPhone时刻'——它叫什么？" → Transformer。论文标题：《Attention Is All You Need》。 |
| **LLM** | "三个字母，代表'大语言模型'。ChatGPT里的GPT、文心一言、通义千问——它们统称什么？" → LLM（Large Language Model）。 |
| **Prompt** | "你对AI说的话，你给AI的指令——这个东西叫什么？" → Prompt（提示词）。记住：Prompt质量决定输出质量。 |
| **AI幻觉** | "AI有时会'一本正经地胡说八道'，编造不存在的参考文献、虚构数据——这个现象叫什么？" → AI幻觉（Hallucination）。识别幻觉，是使用AI的基本功。 |
| **Agent** | "不是让AI直接回答问题，而是让AI自主规划步骤、调用工具、逐步完成任务——这种工作模式叫什么？" → Agent（智能体）。这是AI应用的下一个范式。 |
| **MCP** | "让AI连接外部工具和数据源的开放协议——就像AI的'USB接口'，插上什么就能用什么。这个协议叫什么？" → MCP（Model Context Protocol）。Anthropic提出的行业标准。 |

> "如果这七个概念你都清楚，恭喜你——这节课的核心知识你已经掌握了。如果有两三个不太确定，记下来，课后花十分钟回顾一下讲义附录。"

### 🎓 学生版

#### 作业一：AI工具对比笔记（必做）

| 项目 | 内容 |
|------|------|
| **任务** | 用以下三个问题，分别向至少3个不同的AI工具提问（推荐：ChatGPT、Claude、文心一言、通义千问、DeepSeek、Kimi中任选3个），对比它们的回答质量，写一份400字以上的对比笔记。 |
| **提交方式** | 课程群内提交Word或PDF文件，命名格式：`姓名_AI工具对比笔记_第1课` |
| **截止时间** | 下次课前一天 22:00 |
| **最低字数** | 400字 |

**三个测试问题：**

> **问题1（逻辑推理）：** "一个水池有一个进水管和一个出水管。进水管单独注满需要3小时，出水管单独排空需要4小时。如果两根管子同时打开，注满水池需要多少小时？请详细解释你的解题步骤。"
>
> **问题2（专业知识）：** "结合你的专业，请解释[选择一个你本专业的基础概念，如'混凝土的徐变'/'二极管的伏安特性'/'色彩三要素']，要求：①用通俗语言解释概念 ②说明为什么这个概念重要 ③举一个实际工程/应用中的例子。"
>
> **问题3（创意写作）：** "假如你是一栋智能建筑，请以第一人称写一篇300字的日记，描述你一天中'看到'和'经历'的事情。要求有温度、有细节、有人文关怀。"

**对比维度（你的笔记需要覆盖以下内容）：**

| 维度 | 说明 |
|------|------|
| **回答质量排名** | 三个问题分别排名，说明理由 |
| **准确性** | 哪个回答最正确？哪个有错误或幻觉？ |
| **深度与细节** | 谁的解释最深入？谁的过于表面？ |
| **语言风格** | 谁的表达最自然？谁的像"机器翻译"？ |
| **速度** | 谁的响应最快？最慢？ |
| **各自弱点** | 每个工具在哪个问题上表现最差？为什么？ |

> **为什么做这个作业？** 我希望你从一开始就养成"不把AI当神谕"的习惯——多个AI交叉验证，批判性使用，而不是盲目相信某一家。这个习惯，会让你在未来的学习和工作中少踩无数坑。

#### 作业二：传统方法 vs AI方法效率对比（必做）

| 项目 | 内容 |
|------|------|
| **任务** | 从你的专业中选取一个真实的任务，分别用"传统方法"和"AI辅助方法"完成，记录并对比两种方式的效率、质量和体验。 |
| **提交方式** | 课程群内提交，命名格式：`姓名_效率对比实验_第1课` |
| **截止时间** | 下次课前一天 22:00 |
| **最低字数** | 500字 |

**实验流程：**

```
第一步：选择一个你近期真正需要完成的任务（不要虚构）
  例如：
  - 写一篇2000字的课程论文大纲
  - 分析一组实验数据并画图
  - 为一个设计方案写文字说明
  - 整理一份参考文献列表（10篇以上）
  - 准备一个课堂展示的PPT大纲
  - 翻译一段专业英文文献（800字以上）

第二步：先用传统方法完成
  - 计时（从开始到完成花了多久？）
  - 记录过程（你用了什么工具？查了什么资料？遇到什么困难？）
  - 评估结果（你对成品满意吗？如果是考试打分，你能得多少分？）
  - 记录感受（过程中最痛苦的是什么？）

第三步：再用AI辅助方法完成（同一个任务！）
  - 使用任意AI工具辅助
  - 同样计时、记录过程、评估结果、记录感受
  - 注意：AI辅助 ≠ 完全让AI做。你是主导者，AI是你的助手。

第四步：对比分析
  - 时间对比
  - 质量对比
  - 体验对比
  - 你的真实感受和反思
```

**记录模板（建议使用）：**

| 对比维度 | 传统方法 | AI辅助方法 |
|----------|----------|------------|
| **任务描述** | （同一个任务） | （同一个任务） |
| **所用时间** | XX分钟 | XX分钟 |
| **所用工具/资源** | （列出） | （列出） |
| **成品质量自评** | 1-10分 | 1-10分 |
| **对结果的信任度** | 1-10分 | 1-10分 |
| **最困难的环节** | （描述） | （描述） |
| **最惊喜的发现** | （描述） | （描述） |

> **为什么做这个作业？** 听我说一百遍"AI能提高效率"，不如你自己亲手做一遍。当你亲眼看到完成同一个任务，时间从两小时变成二十分钟——那种冲击，是任何讲解都无法替代的。这就是"体验式学习"。

```
场景2：【场景名称】

  - AI应用：
  - 预期效果：

```

**示例（供参考，请不要照抄——写你自己的）：**

```
场景：毕业设计文献综述

```

> **为什么做这个作业？** 这节课的主题是"AI的发展与未来"——但这个"未来"，最终要跟你个人的未来产生联系。这个作业就是让你把AI从"别人的技术"变成"我的工具"。当你写出了5个场景，你对AI的认知就会从"这个好厉害"变成"这个对我有用"——这才是真正的学习发生了。

> **为什么做这个作业？** 作为企业管理者或从业者，你未来每天都要跟AI打交道。从一开始就建立多AI交叉验证的习惯——不同的AI对同一个商业问题会给出完全不同的视角。这个习惯，会帮你避免"被某一家AI带偏"的风险。同时，通过对比，你也能快速判断哪个AI最适合你的行业和场景。

### 语气与节奏

1. **核心回顾环节：** 语速适中偏快，每句话之间有一个小停顿，像是在帮学生"归档"知识。语调肯定、干脆。每讲完一句话，可以加一个"记住了吗？"——不用等回应，自问自答即可，作用是制造节奏感。

2. **💼 企业翻译环节：** 从学生语气切换到商业语气——更直接、更务实、更有"这个能帮你省钱/赚钱"的暗示。可以加入"这条你在下周例会就能用"这样的提示。如果课堂同时有学生和企业学员，可以在讲完每条商业翻译后，对学生说"你们也别走神——等你进了职场，这一条就是你的竞争力。"

3. **作业说明环节：** 切换到"班主任模式"——清晰、具体、不容含糊。让学生明确知道什么时候交、交什么、为什么做。强调"必做"和"选做"的区别时，对于第三个作业的"强烈推荐"要带上鼓励的笑容。双受众时，先讲🎓学生版再讲💼企业版，中间用"接下来是企业版的作业"做切换提示。

4. **下节课预告环节：** 语气兴奋但不浮夸。像是在透露一个"秘密"，让学生产生期待。RCTE框架不要展开讲——点到为止，留悬念。企业学员的补充一句话即可，不要喧宾夺主。

5. **结束语环节：** 这是全场最重要的情感表达。从"知识回顾"的自然音量，逐渐降低，语速放慢。特别是讲到图灵提问那一段，建议有一个2-3秒的停顿——让问题悬在空中。最后"欢迎大家来到AI时代"时，音量提高，语气坚定而温暖，像在迎接他们进门。**新增的双受众收尾**：先面向全体讲完图灵和时代的部分（统一情感线），然后区分面向——对学生温暖鼓励（"你比99%同龄人领先"），对企业学员坚定有力（"竞争对手已经在看了"）。两个收尾之间可以有一个轻微的转身或视线切换，帮助观众识别切换。

### 重点强调

- **五句话核心回顾是"复习锚点"。** 如果时间紧张，宁可压缩作业说明，也要完整讲完这五句话。因为它们是学生课后唯一可能完整记住的内容，是整节课的"最小知识单元"。
- **💼 商业翻译不是"加餐"而是"转化器"。** 对在场的每一位企业学员来说，这30-60秒才是整节课最值钱的内容。即使时间紧张，也至少要把五句商业翻译快速过一遍。
- **不要跳过结束语。** 结束语不是"凑时间"的，而是整节课的"情感锚点"。知识会被遗忘，但那种"我是参与者/驾驭者"的感觉会留下来。这比多讲一个技术细节重要得多。
- **让学生拍照作业要求。** 在讲到作业时，明确说："请大家拿出手机，把这页拍下来。"确保学生回去后不会因为"忘了具体要求"而放弃做作业。
- **作业二的实验流程必须讲清楚。** 这个作业是新奇的——学生可能从来没有做过"对比实验"。花一分钟时间把四步流程讲透，否则很多学生会因为不知道"怎么做"而敷衍。
- **混合受众课堂：注意切换信号。** 在内容从🎓切换到💼时，用明确的语言提示（如"接下来这一段是专门给企业学员的"），避免让任何一方觉得"这段跟我没关系"而走神。

### 备课建议

1. **准备两个版本的作业群公告模板。** 🎓学生版和💼企业版分别准备，下课第一时间发到课程群。确保两版都包含完整的作业要求和截止时间。文案建议用"同学你好"开头，写上助教联系方式。

2. **提前想好催作业策略。** 第一次课的作业完成率往往决定后续整个课程的学习效果。建议在截止日前一天傍晚，在群里发一条友好的提醒。企业版作业可能需要更早提醒（因为涉及内部数据梳理）。

3. **结束语可能需要练习。** 如果感觉背不下来，可以用关键词提示卡（不用逐字稿）："视角转变 → 图灵之问 → 你自己回答 → AI时代欢迎你 → 学生收尾 → 企业收尾"。自然的表达比背诵更有感染力。特别注意新增的双受众收尾部分的语气切换，建议课前单独练两遍。

4. **如果下课时间已经到了但还没讲完：** 优先确保完成"五句话核心回顾"和"结束语"。作业说明可以缩短为"详见群公告"。💼商业翻译可以压缩为一句话："五句话的商业版在讲义里有，企业学员课后看一下"。下节课预告缩短为一句话即可。

5. **准备应对混合受众的课堂动态。** 如果课堂中同时有🎓学生和💼企业学员，注意观察双方的反应差异。学生可能对"图灵之问"产生共鸣，企业学员可能对"机会矩阵"更感兴趣。结束后的Q&A环节可以分别cue两类受众——"同学们有什么问题？企业这边的朋友呢？"

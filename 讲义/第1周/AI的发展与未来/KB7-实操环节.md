## 三、实操前准备（2分钟）

### 3.1 教师课前检查清单

在课程开始前，请确认以下事项：

- [ ] 机房网络连通（打开浏览器访问 https://www.baidu.com 确认）
- [ ] 测试访问 https://chat.openai.com / https://claude.ai / https://gemini.google.com 至少一个可通（境外工具）
- [ ] 测试访问 https://chat.deepseek.com / https://kimi.moonshot.cn （国内工具必须可通——这是保底方案）
- [ ] 投影仪/大屏就绪，能够实时展示教师操作
- [ ] 确认学生已知机房基本规则（不浏览与课程无关的网站等）
- [ ] 准备好板书/PPT上的备用方案提示（见第八节）
- [ ] **心理准备**：实操课一定有学生掉队、网络卡顿、注册失败等情况——这是正常的，不要慌，按备用路径走即可

### 3.2 学生就绪检查（教师口头指令）

> **教师说**："同学们，在正式开始之前，请大家做三件事：
> 1. 打开浏览器（推荐Chrome或Edge），确保能打开百度首页。
> 2. 检查电脑的输入法是否切换到中文模式——待会儿我们需要同时使用中文和英文。
> 3. 如果你有自己的邮箱（QQ邮箱、163邮箱都可以），请先登录——注册时可能需要验证。"

### 3.3 关键心态提示（教师务必强调）

> **教师说**："在开始之前，我要先说三件重要的事：
>
> **第一**，如果你在注册过程中卡住了、打不开网页、收不到验证码——请举手示意，我会过来帮你。不要自己闷着，也不要放弃。
>
> **第二**，如果你发现某个网站无法访问（比如ChatGPT在某些网络环境下打不开），**这是完全正常的**，不是你操作的问题。请跳过去，按照屏幕上的备用方案继续下一个工具。
>
> **第三**，这节课的目标不是'把所有工具都注册一遍'，而是'至少成功体验一个AI工具，并对它有一个真实的感受'。哪怕你只用了DeepSeek，只要你和它聊了天、问了问题，这节课就算成功了。"

## 四、分步注册引导

---

### 步骤1：注册ChatGPT（约10分钟，必要时可跳过）

> **注意**：此环节需要访问境外网站。如果课堂网络不支持，请教师直接宣布跳至步骤4（国内工具）。

#### 4.1.1 教师屏幕投影演示（3分钟）

**教师操作——请按顺序投影，每一步停顿5秒等待学生跟随**：

```
第1步：打开浏览器，在地址栏输入：https://chat.openai.com
        按回车键。

第2步：页面加载后，点击页面中央的「Sign up」（注册）按钮。
        或点击「Get started」（开始使用）。

第3步：选择注册方式（三选一）：
        □ 方式A：Google账号登录（推荐，如果你有Gmail的话）
        □ 方式B：Microsoft账号登录  
        □ 方式C：输入邮箱地址 → 设置密码 → 邮箱验证
        （推荐学生使用方式C——QQ邮箱或163邮箱即可）

第4步（方式C）：输入你的邮箱地址 → 点击「Continue」
                 → 设置一个密码（至少8位，包含字母和数字）
                 → 检查邮箱收件箱（包括垃圾邮件文件夹）
                 → 点击验证邮件中的链接

第5步：验证手机号（可能需要）：
        - 选择国家代码 +86（中国）
        - 输入手机号
        - 接收并输入短信验证码
        - ※如果收不到验证码，说明当前网络环境受限，跳至步骤4

第6步：注册成功后，页面会自动跳转到ChatGPT对话界面。
        看到对话框和"Message ChatGPT"提示，说明注册成功！
```

#### 4.1.2 第一句提示词——让学生感受"和AI对话"（2分钟）

> **教师指令**："注册成功的同学，请在对话框里**复制粘贴**下面这段话，然后按回车发送："

```
你好！请用三句话介绍你自己，包括：你是谁、你能做什么、你的知识截止日期是什么时候。
```

> **教师说**："看看ChatGPT怎么回答。注意它是用中文回答的——你用什么语言问，它就用什么语言答。这就是AI的'多语言能力'。"

**预期结果**：ChatGPT会回复一段自我介绍，说明它是GPT模型、能做什么、知识截止到什么时候。

#### 4.1.3 第二句提示词——针对学生身份定制（3分钟）

> **教师指令**："接下来，请根据你自己的专业，选择或修改下面的提示词，粘贴发送："

```
（模板——请学生替换【】中的内容）
我是一名【工程设计】专业的大二学生，之前没有学过编程和人工智能。
请用通俗易懂的语言，结合我专业的实际应用场景，向我解释什么是"机器学习"。
```

> **教师提示**："你可以把'工程设计'改成你自己的专业——比如'护理'、'会计'、'电子商务'、'学前教育'。这是AI的一个超强能力：**它可以用你听得懂的方式，解释你不懂的东西**。"

> 💼 **企业版试用**（企业学员请用以下提示词替代上面的学生版）：
> ```
> 我是一家50人科技公司的管理者。请用非技术语言解释什么是机器学习，
> 并说明它在企业中最可能的应用场景。
> ```
> **教师说明**："企业学员请用这个版本。这能帮你从管理者视角理解AI的商业价值，而不仅仅是技术定义。"

**预期结果**：ChatGPT会生成一段通俗解释，并结合学生专业（或企业管理场景）给出例子。

#### 4.1.4 如果ChatGPT无法访问——教师处理

> **教师说**："如果打不开ChatGPT网站、或者注册到一半卡住了——请停下来，不用纠结。这不是你的问题，是网络限制。我们接下来还有很多其他的AI工具可以用。请回到我们的流程，跳到步骤4（国内工具）。"

**教师注意**：不要在ChatGPT环节和学生一起死磕网络问题。30秒搞不定就让学生跳过。

### 步骤2：注册Claude（约10分钟，可选/可跳过）

> **教师引入**："ChatGPT注册成功的同学，我们来看第二个工具——Claude。它来自另一家AI公司Anthropic，在编程和逻辑推理方面表现很出色。我们将用同样的题目测试它，然后对比两个AI的回答有什么区别。"

#### 4.2.1 注册步骤（教师投影演示，3分钟）

```
第1步：打开浏览器新标签页，输入：https://claude.ai
        按回车键。

第2步：点击「Continue with Google」（Google登录）
        或 点击「Continue with email」（邮箱登录）
        推荐使用Google登录（如果你刚才注册ChatGPT时用了Google）

第3步：按页面提示完成信息填写（姓名、邮箱确认等）

第4步：注册成功后会进入Claude对话界面。
        界面上方显示"Claude"，下方是输入框。
        如果看到对话框，说明注册成功！
```

#### 4.2.2 代码生成测试——展示Claude的编程能力（5分钟）

> **教师指令**："注册成功的同学，复制粘贴下面的提示词。这是一道编程题，我们看看Claude能不能写出来："

```
请用Python写一个完整的程序，实现以下功能：

要求：
1. 生成1到100之间的所有素数
2. 计算这些素数的总和
3. 在程序最后，用print()打印出"1到100之间的素数共有XX个，它们的总和是YY"

请给出完整代码，并确保代码可以直接运行。
```

> **教师操作**：将Claude生成的代码展示在投影上。
>
> **教师说**："看看Claude生成的代码——不仅给出代码，通常还会在代码前后加上解释。这种'理解需求→写出代码→附加解释'的能力，让Claude成为很多程序员的首选助手。"

> 💼 **企业版**（企业学员请额外测试以下提示词，感受Claude在职场写作中的能力）：
> ```
> 请写一封内部邮件，向团队宣布公司将开始使用AI工具辅助日常工作。
> 要求：
> 1. 语气积极但务实，不要过于狂热
> 2. 说明公司引入AI的目的（提高效率、减少重复劳动）
> 3. 明确这不是取代员工，而是赋能员工
> 4. 列出2-3个员工可以马上尝试的简单AI应用场景
> 5. 控制在200-300字
> ```
> **教师说明**："企业学员注意观察Claude的邮件写作能力——语气是否得体？结构是否清晰？这类'内部沟通文案'是企业中最常见的AI应用场景之一。"

#### 4.2.3 ChatGPT与Claude对比速览（师生互动，2分钟）

> **教师说**："刚才用同一个问题问了两个不同的AI。有没有同学发现它们的回答有什么不同？比如语气、详细程度、代码组织方式？请一位同学分享一下你的观察。"

**预期观察点**：
- Claude回答通常更温和、更像人
- ChatGPT回答可能更简洁直接
- 两者都能正确写出代码，但解释风格不同

#### 4.2.4 如果Claude无法访问——处理方式

> **教师说**："和ChatGPT一样，Claude在某些网络环境下也无法访问。如果打不开，没关系——我们有国内工具。"

### 步骤3：注册Gemini（约8分钟，可选/可跳过）

> **教师引入**："接下来是谷歌的Gemini——三大AI之一。它的亮点是**多模态**能力，也就是可以直接识别和描述图片。我们一起来试试。"

#### 4.3.1 注册步骤（3分钟）

```
第1步：打开浏览器新标签页，输入：https://gemini.google.com
        按回车键。

第2步：点击「Sign in」或「登录」，使用Google账号登录。
        ※ Gemini要求Google账号，如果没有Google账号，请跳过Gemini。

第3步：登录成功后进入Gemini首页，看到"Hello, [你的名字]"表示成功。
```

#### 4.3.2 图片识别测试——感受多模态能力（5分钟）

> **教师指令**："现在我们来试试Gemini的看家本领——图片识别。请做以下操作："

```
任务：让Gemini描述一张图片。

方法A（电脑端）：
1. 在浏览器中搜索任意一张图片——比如"埃菲尔铁塔"、"一只猫"等
2. 右键保存图片到桌面
3. 在Gemini对话框中，点击输入框左侧的「+」或图片图标
4. 选择刚才保存的图片上传
5. 在输入框输入："请描述这张图片里的内容，包括你看到了什么物体、
   什么场景、什么颜色。如果是著名地标，请告诉我它的名字和历史。"
6. 按回车发送

方法B（手机端）：
直接拍照然后上传到Gemini对话中，输入同样的提示词。
```

> **教师说**："ChatGPT和Claude的最新版本也能识别图片了，但这是Gemini最早就有的功能。注意看它描述得多详细——甚至连图片里你没有注意到的细节它都会说出来。"

**如果Gemini无法访问**：跳至步骤4或步骤5。

### 步骤4：体验Perplexity（约8分钟，可选/可跳过）

> **教师引入**："前三个工具都是'聊天型AI'。现在我们换一个类型——**AI搜索**。Perplexity把AI和搜索引擎结合在了一起，它的每一个回答都会附上信息来源链接，就像一篇带参考文献的小论文。"

#### 4.4.1 注册步骤（2分钟）

```
第1步：打开浏览器新标签页，输入：https://www.perplexity.ai
        按回车键。

第2步：点击右上角「Sign Up」→ 选择Google登录或邮箱登录。
        无需付费，免费版即可使用。

第3步：注册完成后进入搜索界面。
        界面中间是搜索框，左侧有功能菜单。
```

#### 4.4.2 AI搜索 vs 传统搜索——对比体验（5分钟）

> **教师指令**："分别在百度/必应和Perplexity中搜索同一个问题，看看有什么不同："

```
搜索问题（请分别在百度搜索和Perplexity中各输入一次）：
"2025年诺贝尔物理学奖颁给谁？为什么这个奖项和人工智能有关？"

对比要点（教师请学生观察）：
1. 百度给你的是一堆链接，你需要自己点开、阅读、总结
2. Perplexity直接给你一个完整的答案，还注明了每个信息来自哪个网站
3. Perplexity的答案最后有来源链接，你可以点进去验证
```

> **教师提问**："有同学觉得AI搜索可以完全替代百度吗？——不能，因为AI搜索可能出错，来源链接就是你验证真假的途径。"

#### 4.4.3 如果Perplexity无法访问——替代方案

| 替代工具 | 网址 |

### 步骤5：注册国内AI工具（10分钟）⭐ **核心环节，不可跳过**

> **教师说**："好了，不管前面的工具你注册成功了多少，接下来的国内AI工具**每一个人都必须至少注册一个**。这是我们今天实操课的底线目标。它们不需要任何特殊网络环境，直接用手机号或微信就能注册。"

#### 5.1 DeepSeek（深度求索）——注册+首次对话（4分钟）

```
第1步：打开浏览器，输入：https://chat.deepseek.com
        按回车键。

第2步：点击页面上的「登录/注册」
        选择方式：
        □ 手机号 + 验证码（推荐，最快捷）
        □ 微信扫码登录
        □ 邮箱注册

第3步：登录成功后，进入对话界面。
        恭喜！你现在正在使用目前国内最强的大语言模型之一。
```

> **教师指令——第一句提示词**："注册成功的同学，在对话框中输入："

```
你好！请你做三件事：
1. 用三句话做自我介绍
2. 介绍你和其他AI（比如ChatGPT）相比有什么特点
3. 用一句简短的话鼓励我今天开始认真学习AI
```

> **教师指令——第二句提示词**："再输入下面这段话，感受DeepSeek的推理能力："

```
请一步一步推理下面的问题：

"小明说：'我昨天看到一本书，它的价格是48元，但我只花了24元就买到了，因为书店打了五折。'
小明的计算对吗？请写出你的推理过程。
```

**预期效果**：DeepSeek会展示详细的逐步推理过程（英文俗称Chain of Thought），让学生看到AI不只是"吐出答案"，而是像人一样思考。

> 💼 **企业版**（企业学员请额外测试以下提示词，体验DeepSeek在企业场景中的推理能力）：
> ```
> 我是一家制造企业的运营主管。我们最近发现生产线上的次品率从2%上升到了5%。
> 请一步一步帮我分析可能的原因，并给出一个系统性的排查方案。
> 要求：
> 1. 按照"人-机-料-法-环"五个维度分类分析
> 2. 每个维度给出至少2个可能的原因
> 3. 最后给出一个排查优先级排序
> ```
> **教师说明**："企业学员注意——DeepSeek以推理能力著称。观察它是如何结构化地分析一个真实的企业问题的。这类'根本原因分析'在企业日常管理中非常实用。"

#### 5.2 Kimi（月之暗面）——注册+长文档上传测试（3分钟）

```
第1步：打开浏览器新标签页，输入：https://kimi.moonshot.cn

## 五、教师巡查指南

### 5.1 走到学生中间——看什么

> **教师注意**：在这个环节，你最主要的角色不是在讲台前操作，而是**在机房中走动**，观察每个学生的屏幕。

| 观察点 | 说明 |
|--------|------|
| 屏幕上是否打开了正确的网页 | 有些学生可能打开了其他网站或不知道下一步做什么 |
| 是否卡在注册页面 | 验证码收不到、密码设置不通过、不知选哪个登录方式 |
| 是否成功发出了第一个提示词 | 看到对话框里有AI的回复才算完成 |
| 是否在对照表格填写 | 如果学生没在填表，可能没有认真做对比测试 |
| 学生表情 | 皱眉=卡住了；无聊=跟不上；被忽略的学生最需要帮助 |
| 企业学员是否在做企业版测试题？ | 如果企业学员在用学生版提示词，轻声提醒他们切换到💼企业版。他们的Prompt是否足够具体（包含行业、公司规模、具体场景）？ |

### 5.2 常见问题与快速解决

| 常见问题 | 快速解决方案 |
|----------|------------|
| ChatGPT/Claude打不开 | "这很正常，跳过它，用DeepSeek或Kimi。这些在国内网络下就能用。" |
| 邮箱收不到验证码 | "检查垃圾邮件文件夹。如果2分钟还没收到，换个邮箱或者改用手机号注册。" |
| 手机号注册提示"已注册" | "可能你之前注册过。试试'忘记密码'，或者直接用微信扫码登录。" |
| 学生不知道问什么 | "用我投影上的提示词，直接复制粘贴——不用自己想问题。" |
| 学生说"AI的回答我看不懂" | "可以把AI的回答再粘贴回去，然后说'请用更简单的语言解释一下'——AI可以自己解释自己。" |
| 学生对中文回答不满意 | "在问题后面加一句'请更详细一些'或'请用更专业的语言'，可以调整回答风格。" |
| 有学生已经全部完成，无事可做 | 告诉他们："试试问AI一个你一直好奇但没人能解释清楚的问题——任何问题都可以。" |

### 5.3 如何帮助学生——不自作，不代劳

> **教师注意**：实操课最容易犯的错误就是直接上手帮学生点鼠标、打键盘。这样做学生学不到东西。

**正确的帮助方式**：
- ✅ 站在学生旁边，用语言描述步骤："先看屏幕右上角，有没有看到一个蓝色的按钮？"
- ✅ 指着屏幕但不碰鼠标："你点这里试试。"
- ✅ 问学生："你做到哪一步卡住了？让我看看你现在的屏幕。"
- ❌ 直接拿过学生的鼠标帮他操作
- ❌ 在学生键盘上直接打字
- ❌ 说"算了你别弄了，看你同桌的就行"

### 5.5 混班教学提示：管理🎓学生版与💼企业版并存的课堂

> **教师注意**：当课堂中同时有学生学员和企业学员时，实操环节需要额外注意以下几点：

**课前准备**：
- [ ] 提前了解班级中学员和企业学员的大致比例
- [ ] 在投影/PPT中同时展示🎓和💼两套提示词，用不同颜色或标签区分
- [ ] 确保企业学员清楚：他们使用的是💼企业版提示词，内容更贴近职场场景

**课中执行**：
- ✅ 在宣布每个实操步骤时，同时念出两种提示词的选择："学生请用🎓版本，企业学员请用💼版本"
- ✅ 巡查时优先检查企业学员——他们可能不熟悉课堂环境，更容易跟丢
- ✅ 如果企业学员用错了版本（用了学生版），不要当众纠正，走到旁边轻声提醒
- ✅ 对比测试讨论环节（6.3），可以有意邀请一位学生学员和一位企业学员分别分享——自然展示两个群体的不同视角

**分组建议**（如果条件允许）：
- 将企业学员和学生学员穿插安排座位——方便互相帮助（企业学员可能在操作上需要学生帮助，但能在讨论中提供职场视角）
- 对比测试环节，可以让同桌的学生和企业学员交换看对方的AI回答——这是非常有价值的跨视角学习

**常见问题预判**：
| 情况 | 处理方式 |
|------|----------|
| 企业学员说"我是来学AI的，不是来学写邮件的" | "写邮件只是练习形式。你真正在学的是——如何给AI下需求、如何判断AI输出的质量、如何把AI嵌入工作流。这些能力在任何岗位都通用。" |
| 学生学员问"我能不能也试试企业版的题？" | "当然可以！企业版的题对你也有价值——它们让你提前看到职场上AI是怎么用的。时间充裕的话，欢迎都试试。" |
| 两类学员的进度不同步 | "企业学员如果已完成企业版测试，可以回头试一题学生版；学生学员同理。互相对比两种场景下AI的差异，本身就是很好的学习。" |

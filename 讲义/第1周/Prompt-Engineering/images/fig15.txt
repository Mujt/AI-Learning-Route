用户触发操作
    │
    ▼
┌─────────────────────────────────────────────────────┐
│              Permission Gate 决策流程                  │
│                                                     │
│  操作类型: rm -rf /project/temp/                     │
│  风险等级: HIGH (不可逆文件删除)                        │
│                                                     │
│  ┌───────────────────────────────────────────┐      │
│  │            四级决策矩阵                      │      │
│  │                                           │      │
│  │  Allow    → 自动放行    (白名单操作)         │      │
│  │  例: 读取公开文件、执行 SELECT 查询          │      │
│  │                                           │      │
│  │  Ask      → 每次询问    (默认级别)           │      │
│  │  例: 修改代码文件、创建 PR                  │      │
│  │                                           │      │
│  │  Deny     → 直接拒绝    (黑名单操作)         │      │
│  │  例: 访问 ~/.ssh/、执行 DROP DATABASE       │      │
│  │                                           │      │
│  │  AskOnce  → 仅首次询问  (会话级缓存)         │      │
│  │  例: 同目录下的批量文件操作                  │      │
│  └───────────────────────────────────────────┘      │
│                                                     │
│  输出: Ask → 弹出确认对话框 → 用户选择 Allow/Deny      │
└─────────────────────────────────────────────────────┘

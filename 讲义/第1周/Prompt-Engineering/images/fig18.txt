Agent 生命周期中的 Hook 注入点：

会话开始
    │
    ▼
┌─────────────────┐
│   Notification  │  ← "会话已启动" → 初始化资源/预热缓存
└────────┬────────┘
         │
    ┌────▼────┐
    │  LLM    │  思考/推理
    │  Think  │
    └────┬────┘
         │
         │  决定调用工具
         │
    ┌────▼────────────┐
    │  PreToolUse     │  ← 工具调用前拦截
    │                 │     · 参数校验/脱敏
    │  Hook 触发      │     · 权限二次确认
    │                 │     · 预算检查
    └────┬────────────┘
         │
    ┌────▼────┐
    │  Tool   │  执行
    │  Execute│
    └────┬────┘
         │
    ┌────▼────────────┐
    │  PostToolUse    │  ← 工具调用后拦截
    │                 │     · 结果脱敏
    │  Hook 触发      │     · 日志记录
    │                 │     · 输出校验
    └────┬────────────┘
         │
         │  (循环直到任务完成)
         │
    ┌────▼────────────┐
    │   Stop          │  ← 会话结束
    │                 │     · 清理临时资源
    │  Hook 触发      │     · 生成摘要报告
    │                 │     · 通知用户
    └─────────────────┘

## 二、课程结构（8 个章节）

| 章节 | 内容 | 教学要点 |
|------|------|----------|
| 一 | 当前有哪些「AI 办公自动化」实例 | OpenClaw（龙虾）、WorkBuddy 等，建立"AI 能接管软件"的直观认知 |
| 二 | 这些自动化工具背后的原理 | 大模型是"嘴"不是"手脚"，引出 Skills 与 MCP 两个核心概念 |
| 三 | Skills 和 MCP 到底有什么区别 | 对比表 + 决策树 + 案例对照（参考《补充知识/Skill 与 MCP 的选型》） |
| 四 | Agent 的工作流程 | Agent 主循环（观察→思考→决策→执行→反馈），如何调用 Skill / MCP |
| 五 | 回顾：Skills 的开发流程 | SKILL.md 结构、frontmatter、"让 AI 帮你写 Skill" |
| 六 | 实战：MCP 如何开发（详细） | 核心概念 → 最小示例 → 待办事项管理实战 → 七步流程 → 接入配置 |
| 七 | 总结：缺点与后续改进 | 手动触发/单 Agent/无记忆等 7 个缺点，引出多 Agent、记忆、编排 |
| 八 | 课后作业 | 4 道题（2 必做 2 选做） |

## 四、教学建议

1. **主线递进**：现象（实例）→ 原理（Skills/MCP）→ 区分 → Agent 工作流 → 回顾 Skill → 开发 MCP → 反思改进，环环相扣，建议按文档顺序讲。
2. **重点章节**：第三章（Skills vs MCP 区分）和第六章（MCP 开发实战）是本课核心，需留足实操时间。
3. **零基础友好**：代码均由 AI 辅助生成，强调"描述需求 + 运行 + 检查"，降低编程门槛。

### 第一部分：函数（Functions）

#### 4.1.1 为什么需要函数

**生活类比：餐厅厨房**

想象你去一家餐厅吃饭。你点了一道"宫保鸡丁"，厨房就开始按照固定的**菜谱**操作：

1. 准备食材（鸡肉丁、花生、辣椒、葱姜蒜）
2. 调料汁（酱油、醋、糖、淀粉）
3. 热锅倒油，爆香辣椒和葱姜
4. 下鸡肉翻炒至变色
5. 倒入料汁和花生，翻炒均匀
6. 出锅装盘

这个"菜谱"就是一个**函数**：

- 菜谱有**名字**：宫保鸡丁
- 菜谱有**原材料（参数）**：鸡肉、花生、调料
- 菜谱有**操作步骤（函数体）**：切、炒、调味
- 菜谱有**成品（返回值）**：一盘菜

**为什么需要菜谱？** 因为每次有人点这道菜，厨师不需要重新发明做法 —— 照着菜谱做就行。这就是编程中的 **DRY 原则（Don't Repeat Yourself）**。

**代码对比：没有函数 vs 有函数**

```python
# ===== 没有函数：代码重复 =====
# 计算学生A的总分
scores_a = [85, 90, 78]
total_a = 0
for s in scores_a:
    total_a += s
avg_a = total_a / len(scores_a)
print(f"学生A 平均分：{avg_a:.1f}")

# 计算学生B的总分 — 几乎一模一样的代码又写了一遍！
scores_b = [92, 88, 95]
total_b = 0
for s in scores_b:
    total_b += s
avg_b = total_b / len(scores_b)
print(f"学生B 平均分：{avg_b:.1f}")

# 如果有100个学生呢？要复制粘贴100次？太可怕了！

# ===== 有函数：一次定义，多次使用 =====
def calculate_average(scores):
    """计算成绩列表的平均分"""
    total = sum(scores)        # sum() 也是内置函数
    avg = total / len(scores)
    return avg

# 干净、简洁、不易出错
print(f"学生A 平均分：{calculate_average([85, 90, 78]):.1f}")
print(f"学生B 平均分：{calculate_average([92, 88, 95]):.1f}")
print(f"学生C 平均分：{calculate_average([76, 83, 69]):.1f}")
```

**函数的四大好处**：

| 好处 | 说明 | 类比 |
|------|------|------|
| **减少重复** | 同样的逻辑只写一次 | 菜谱写一次，用无数次 |
| **易于维护** | 改一处，所有调用都生效 | 菜谱改良，所有菜都变好吃了 |
| **便于理解** | 函数名描述了它做什么 | "宫保鸡丁"比"先放油然后..."更清晰 |
| **便于测试** | 可以单独测试每个函数 | 单独品尝酱汁是否调对了 |

#### 4.1.2 函数定义与调用详解

**基本语法**：

```python
def 函数名(参数1, 参数2, ...):
    """文档字符串 — 用一句话说明函数做什么（可选但推荐）"""
    # 函数体 — 具体的操作步骤
    return 返回值  # 可选，没有 return 则返回 None
```

**完整示例**：

```python
# 定义一个函数
def greet(name, greeting="你好"):
    """
    向指定的人打招呼。
    
    参数：
        name: str，对方的名字
        greeting: str，问候语（默认为"你好"）
    
    返回：
        str，完整的问候语
    """
    message = f"{greeting}，{name}！欢迎来到 AI 学习之旅。"
    return message

# 调用函数
result = greet("张三")
print(result)  # 你好，张三！欢迎来到 AI 学习之旅。

result = greet("李四", "早上好")
print(result)  # 早上好，李四！欢迎来到 AI 学习之旅。
```

**关键概念辨析**：

| 概念 | 解释 | 在示例中是什么 |
|------|------|----------------|
| **参数（Parameter）** | 函数定义时括号里的变量名 | `name`, `greeting` |
| **实参（Argument）** | 调用函数时实际传入的值 | `"张三"`, `"早上好"` |
| **函数名（Function Name）** | 函数的标识符 | `greet` |
| **文档字符串（Docstring）** | 三重引号包裹的说明文字 | `"""向指定的人打招呼。..."""` |
| **返回值（Return Value）** | 函数执行后传回的结果 | `"你好，张三！..."` |

> **命名规范**：函数名使用 **小写字母 + 下划线**（snake_case），这是 PEP 8 推荐的 Python 命名风格。例如：`calculate_average`、`get_user_name`、`is_valid_email`。

#### 4.1.3 参数类型详解

Python 函数参数有四种类型，我们逐一讲解。

**（1）位置参数（Positional Arguments）—— 按顺序传参**

```python
def introduce(name, age, major):
    """介绍一位学生"""
    return f"{name}，{age}岁，专业是{major}"

# 按位置传递：第一个参数给 name，第二个给 age，第三个给 major
print(introduce("张三", 20, "工程设计"))
# 输出：张三，20岁，专业是工程设计

# ⚠️ 位置不对会出问题！
print(introduce("工程设计", 20, "张三"))
# 输出：工程设计，20岁，专业是张三 ← 完全乱了！
```

**（2）关键字参数（Keyword Arguments）—— 按名字传参**

```python
# 使用参数名指定，顺序不重要
print(introduce(age=20, major="工程设计", name="张三"))
# 输出：张三，20岁，专业是工程设计

# 混合使用：先写位置参数，再写关键字参数
print(introduce("张三", major="工程设计", age=20))
# 输出：张三，20岁，专业是工程设计

# ⚠️ 错误写法：关键字参数必须在位置参数之后！
# print(introduce(name="张三", 20, "工程设计"))  # 语法错误！
```

**（3）默认参数（Default Values）—— 给参数一个"备选值"**

```python
def create_user(name, role="学生", is_active=True):
    """创建用户，role 和 is_active 有默认值"""
    return {
        "姓名": name,
        "角色": role,
        "状态": "激活" if is_active else "禁用"
    }

# 只传必填参数，其他用默认值
user1 = create_user("张三")
print(user1)  # {'姓名': '张三', '角色': '学生', '状态': '激活'}

# 覆盖默认值
user2 = create_user("李教授", role="教师", is_active=False)
print(user2)  # {'姓名': '李教授', '角色': '教师', '状态': '禁用'}

# ⚠️ 常见陷阱：不要用可变对象做默认参数！
# ❌ 错误写法
def add_item_wrong(item, item_list=[]):  # 默认值 [] 是一个可变对象
    item_list.append(item)
    return item_list

print(add_item_wrong("A"))  # ['A']
print(add_item_wrong("B"))  # ['A', 'B'] ← 预期是 ['B']，但默认列表被"污染"了！

# ✅ 正确写法
def add_item_correct(item, item_list=None):
    if item_list is None:
        item_list = []     # 每次调用都创建新的列表
    item_list.append(item)
    return item_list

print(add_item_correct("A"))  # ['A']
print(add_item_correct("B"))  # ['B'] ← 正确！
```

**（4）`*args` 和 `**kwargs` —— 接受任意数量的参数（了解即可）**

```python
# *args：接受任意数量的位置参数，打包成一个元组（tuple）
def print_all_scores(student_name, *scores):
    """打印学生所有成绩"""
    print(f"{student_name} 的成绩：{scores}")
    print(f"共 {len(scores)} 门课，平均分：{sum(scores) / len(scores):.1f}")

print_all_scores("张三", 85, 90, 78, 92)
# 张三 的成绩：(85, 90, 78, 92)
# 共 4 门课，平均分：86.2

print_all_scores("李四", 88, 95)  # 可以传任意数量
# 李四 的成绩：(88, 95)
# 共 2 门课，平均分：91.5

# **kwargs：接受任意数量的关键字参数，打包成一个字典（dict）
def build_student_profile(name, **info):
    """构建学生档案（灵活字段）"""
    profile = {"姓名": name}
    profile.update(info)  # 把额外信息合并进来
    return profile

s1 = build_student_profile("张三", 年龄=20, 专业="工程设计", 班级="2班")
print(s1)
# {'姓名': '张三', '年龄': 20, '专业': '工程设计', '班级': '2班'}

s2 = build_student_profile("李四", 年龄=21, 专业="机械工程", 宿舍="3号楼501")
print(s2)
# {'姓名': '李四', '年龄': 21, '专业': '机械工程', '宿舍': '3号楼501'}
```

> **现阶段建议**：先重点掌握位置参数、关键字参数和默认参数。`*args` 和 `**kwargs` 了解概念即可，在实际项目中遇到了再深入。

#### 4.1.4 返回值详解

```python
# ===== 单个返回值 =====
def add(a, b):
    return a + b

result = add(3, 5)
print(result)  # 8

# ===== 多个返回值（本质是返回了一个元组） =====
def get_student_stats(scores):
    """计算成绩统计量"""
    avg = sum(scores) / len(scores)
    highest = max(scores)
    lowest = min(scores)
    return avg, highest, lowest  # 实际返回的是 (avg, highest, lowest)

# 方式1：用多个变量接收（元组解包）
avg, high, low = get_student_stats([85, 90, 78, 92])
print(f"平均：{avg:.1f}，最高：{high}，最低：{low}")

# 方式2：用一个变量接收（得到元组）
stats = get_student_stats([85, 90, 78, 92])
print(f"返回的元组：{stats}")          # (86.25, 92, 78)
print(f"类型：{type(stats)}")          # <class 'tuple'>

# ===== 没有 return 语句 =====
def say_hello(name):
    print(f"你好，{name}！")  # 只有 print，没有 return

result = say_hello("张三")
print(f"返回值：{result}")     # 返回值：None
print(f"类型：{type(result)}")  # <class 'NoneType'>

# ===== 用 return 提前结束函数 =====
def check_age(age):
    """检查年龄是否合法"""
    if age < 0:
        return "错误：年龄不能为负数"  # 遇到 return 立即结束
    if age > 150:
        return "错误：年龄不可能超过150岁"
    return f"年龄 {age} 有效"  # 只有通过所有检查才执行到这里

print(check_age(25))   # 年龄 25 有效
print(check_age(-5))   # 错误：年龄不能为负数
print(check_age(200))  # 错误：年龄不可能超过150岁
```

> **关键理解**：`return` 做两件事 —— (1) 立即结束函数执行，(2) 把后面的值传回给调用者。`print()` 只是输出到屏幕供人看，不影响程序逻辑。

#### 4.1.5 作用域概念

**什么是作用域？** 变量的"可见范围"。就好像教室里的学生，在自己班（函数内）的同学互相认识，但隔壁班（另一个函数）里谁是谁就不知道了。

```python
# ===== 局部变量 vs 全局变量 =====

# 全局变量：在函数外部定义，整个文件都能访问
school_name = "未来科技大学"

def show_local():
    # 局部变量：在函数内部定义，只能在函数内部使用
    classroom = "A301教室"    # classroom 是局部变量
    teacher = "王老师"        # teacher 也是局部变量
    print(f"在函数内部：{school_name} {classroom} {teacher}")
    # 可以访问全局变量 school_name ✓
    # 可以访问自己的局部变量 classroom, teacher ✓

show_local()
print(f"在函数外部：{school_name}")  # 可以访问全局变量 ✓
# print(classroom)  # ❌ 报错！classroom 是局部变量，外部看不到

# ===== 函数内部修改全局变量 =====
counter = 0  # 全局变量

def increment_wrong():
    # ❌ 错误：这会在函数内部创建一个新的局部变量 counter
    # 不会修改全局的 counter
    counter = counter + 1  # 这行会报错 UnboundLocalError

# ✅ 正确：使用 global 关键字声明要修改全局变量
def increment_correct():
    global counter  # 告诉 Python：我要用全局的那个 counter
    counter = counter + 1

print(f"初始：{counter}")  # 0
increment_correct()
print(f"第一次 +1：{counter}")  # 1
increment_correct()
print(f"第二次 +1：{counter}")  # 2
```

**最佳实践**：

| 场景 | 建议 | 原因 |
|------|------|------|
| 大部分情况 | 使用局部变量和参数传递 | 安全、清晰、易于测试 |
| 常量 | 使用全局常量（全大写命名） | `PI = 3.14159`、`MAX_STUDENTS = 30` |
| 尽量避免 | 用 `global` 修改变量 | 容易导致难以追踪的 bug |

```python
# 推荐模式：通过参数传进去，通过 return 传出来
def calculate_total(items, tax_rate=0.13):
    """计算总价（纯函数：不依赖外部状态）"""
    subtotal = sum(items)
    tax = subtotal * tax_rate
    return subtotal + tax

prices = [100, 200, 50]
total = calculate_total(prices)
print(f"总价：¥{total:.2f}")  # 完全不需要 global
```

#### 4.1.6 函数设计最佳实践

| 原则 | 说明 | 好例子 | 坏例子 |
|------|------|--------|--------|
| **单一职责** | 一个函数只做一件事 | `calculate_average(scores)` | `calculate_and_print_and_save(scores)` |
| **好的命名** | 函数名=动词+名词 | `get_student_name()` | `f1()`、`do_stuff()` |
| **保持简短** | 一个函数尽量不超过20行 | 20行以内 | 200行的"巨无霸"函数 |
| **文档说明** | 复杂逻辑加注释和 docstring | `"""计算 BMI 指数"""` | 完全没有说明 |
| **无副作用** | 尽量通过参数和返回值交互 | `def add(a, b): return a + b` | 在函数内修改全局变量 |

#### 4.1.7 常见函数模式

在实际开发中，函数通常分为以下几种"职责类型"：

```python
# ===== 模式1：验证函数（Validation） =====
def is_valid_email(email):
    """检查是否是有效的邮箱格式"""
    return "@" in email and "." in email.split("@")[-1]

print(is_valid_email("zhangsan@uni.edu.cn"))  # True
print(is_valid_email("not-an-email"))          # False

# ===== 模式2：转换函数（Transformation） =====
def celsius_to_fahrenheit(celsius):
    """摄氏温度转华氏温度"""
    return celsius * 9 / 5 + 32

print(celsius_to_fahrenheit(37))  # 98.6

# ===== 模式3：计算函数（Calculation） =====
def calculate_bmi(weight_kg, height_m):
    """计算体质指数 BMI"""
    return weight_kg / (height_m ** 2)

bmi = calculate_bmi(70, 1.75)
print(f"BMI: {bmi:.1f}")

# ===== 模式4：工厂函数（Factory） =====
# 创建一个指定格式的"问候语生成器"
def build_greeting_generator(greeting_word="你好"):
    """返回一个函数，该函数用指定的问候语"""
    def greet(name):
        return f"{greeting_word}，{name}！"
    return greet

say_hi = build_greeting_generator("Hi")
say_hello = build_greeting_generator("你好")
print(say_hi("Tom"))      # Hi，Tom！
print(say_hello("张三"))  # 你好，张三！
```

> 📊 **企业视角：函数 = 业务流程的可复用单元**
>
> 函数的本质是**"可复用的流程"**。企业AI应用的核心就是把业务流程封装成AI可以调用的函数。
>
> **从"菜谱"类比升级到企业场景**：
> - `calculate_monthly_salary(employee_id)` → 输入员工ID，返回当月应发工资（包含考勤扣款、绩效奖金等复杂规则）
> - `approve_expense(amount, department, category)` → 输入金额/部门/类别，返回是否需要上级审批
> - `generate_sales_report(start_date, end_date, region)` → 输入时间范围和区域，输出完整的销售分析报告
>
> **这对企业AI意味着什么？**
>
> | 函数特性 | 企业映射 | AI应用场景 |
> |---------|---------|-----------|
> | **参数（inputs）** | 业务流程需要的输入数据 | AI Agent调用函数时传入的参数（如"查询2026年7月华东区销售额"） |
> | **返回值（return）** | 业务流程产出的结果 | AI Agent拿到结果后继续推理或展示给用户 |
> | **可复用性** | 一个流程定义好，所有部门都可以调用 | 不需要为每个部门的报销审批写重复的代码 |
> | **单一职责** | 一个函数只做一件事 | 便于AI理解和调用——函数职责越清晰，AI越不容易"用错" |
>
> **核心概念：Function Calling**。当企业使用AI Agent时，AI会自主决定"现在需要调用哪个函数"并自动传参。你企业中定义了多少个清晰、可靠的"业务函数"，就决定了AI Agent能为你自动执行多少种任务。**企业AI的竞争力 = 你能把多少业务流程变成AI可以调用的函数。**

#### 4.2.1 什么是模块

PyPI（Python Package Index）上还有 **超过50万个第三方模块**，几乎任何你能想到的功能，都有人写好了对应的模块。

#### 4.2.2 import 的四种方式

```python
# ===== 方式1：import 模块名（推荐） =====
# 使用模块中的函数时需加模块名前缀
import math

print(math.pi)         # 3.141592653589793
print(math.sqrt(25))   # 5.0
print(math.sin(math.radians(30)))  # 0.5（sin 30°）
# 优点：清晰，一眼就知道 pi、sqrt 来自 math

# ===== 方式2：from 模块 import 具体函数 =====
# 直接使用函数名，不需要前缀
from math import pi, sqrt, sin, radians

print(pi)              # 3.141592653589793
print(sqrt(25))        # 5.0
print(sin(radians(30)))  # 0.5
# 优点：简洁
# 缺点：如果多个模块有同名函数，会冲突

# ===== 方式3：import 模块 as 别名 =====
# 给模块起个短名字，方便反复使用
import numpy as np      # 数据分析领域的通用惯例
import pandas as pd     # 数据分析领域的通用惯例
import matplotlib.pyplot as plt  # 绘图领域的通用惯例

arr = np.array([1, 2, 3, 4, 5])
print(arr.mean())  # 3.0

# ===== 方式4：from 模块 import *（不推荐！） =====
# 把模块中所有公开内容一股脑导入
from math import *
# 优点：不用打前缀
# 缺点：可能意外覆盖已有的变量名，不知道什么来自哪里
# ⚠️ 强烈不推荐在实际项目中使用！
```

**选择建议**：初学阶段优先用 **方式1**（`import module`）和 **方式2**（`from module import name`）。方式3在后续学习 NumPy/Pandas 时会自动熟悉。方式4永远不要用。

```python
# 计算年龄
def calculate_age(birth_date):
    """根据出生日期计算年龄"""
    today = date.today()
    age = today.year - birth_date.year
    # 如果今年的生日还没过，年龄减1
    if today.month < birth_date.month or \
       (today.month == birth_date.month and today.day < birth_date.day):
        age -= 1
    return age

my_birthday = date(2005, 3, 15)
```

**（5）json —— JSON 数据处理**

```python
import json

# Python 中 JSON 对应的数据类型：
# JSON对象   → Python字典(dict)
# JSON数组   → Python列表(list)
# JSON字符串 → Python字符串(str)
# JSON数字   → Python整数(int)或浮点数(float)
# JSON布尔值 → Python布尔值(bool) True/False
# JSON空值   → Python None

# ===== Python → JSON（序列化） =====

# dumps：Python对象 → JSON字符串
student_data = {
    "name": "张三",
    "age": 20,
    "major": "工程设计",
    "scores": [85, 90, 78],
    "is_graduate": False
}

json_str = json.dumps(student_data, ensure_ascii=False)

# 美化输出（indent 参数）
json_pretty = json.dumps(student_data, ensure_ascii=False, indent=2)
print("\n格式化 JSON：")
print(json_pretty)

# ===== JSON → Python（反序列化） =====

# loads：JSON字符串 → Python对象
json_text = '{"course": "AI入门", "duration_weeks": 8, "students": 30}'
course_info = json.loads(json_text)
print(f"\n课程名称：{course_info['course']}")
print(f"课程时长：{course_info['duration_weeks']}周")
print(f"学生人数：{course_info['students']}")

# ===== 保存 JSON 到文件 =====
data_to_save = {
    "date": "2026-07-26",
    "lessons_completed": ["Python基础语法", "函数与模块"],
    "confidence_level": 85
}

with open("learning_progress.json", "w", encoding="utf-8") as f:
    json.dump(data_to_save, f, ensure_ascii=False, indent=2)
print("\n✓ 数据已保存到 learning_progress.json")

# ===== 从文件读取 JSON =====
with open("learning_progress.json", "r", encoding="utf-8") as f:
    loaded_data = json.load(f)
print(f"\n读取的数据：")
print(f"  日期：{loaded_data['date']}")
print(f"  已完成课程：{loaded_data['lessons_completed']}")
print(f"  信心指数：{loaded_data['confidence_level']}%")
```

#### 4.3.1 为什么需要类

**生活类比1：学生档案**

学校要管理5000个学生。每个学生有：
- 信息：姓名、学号、专业、成绩
- 行为：选课、考试、查成绩

如果用列表和字典来存：

```python
# 不用类：数据和行为分离，容易出错
student1 = {"姓名": "张三", "学号": "2024001", "专业": "工程设计", "成绩": [85, 90]}
student2 = {"姓名": "李四", "学号": "2024002", "专业": "机械工程", "成绩": [78, 82]}

# 计算平均分需要"手动操作"
avg1 = sum(student1["成绩"]) / len(student1["成绩"])
avg2 = sum(student2["成绩"]) / len(student2["成绩"])

# 问题：数据和处理数据的逻辑是分离的
# 容易漏掉某个字段，或者对不同学生用了不同的字段名
```

用**类**：把数据结构（属性）和操作这个数据的方法（函数）**打包在一起**：

```python
# 用类：数据和行为封装在一起
class Student:
    def __init__(self, name, student_id, major):
        self.name = name
        self.student_id = student_id
        self.major = major
        self.scores = []
    
    def add_score(self, score):
        self.scores.append(score)
    
    def get_average(self):
        if not self.scores:
            return 0
        return sum(self.scores) / len(self.scores)

# 使用起来自然、不易出错
s1 = Student("张三", "2024001", "工程设计")
s1.add_score(85)
s1.add_score(90)
print(f"{s1.name} 平均分：{s1.get_average():.1f}")
```

#### 4.3.2 类的基本结构

```python
class 类名:  # 类名通常使用大驼峰命名法（PascalCase）：StudentManager, DataProcessor
    """类的文档字符串 — 说明这个类是干什么的"""
```

**关键理解 `__init__` 和 `self`**：

```python
class Dog:
    """一个简单的狗类"""
    
    def __init__(self, name, breed="中华田园犬"):
        """
        __init__ 是"初始化"的缩写。
        当执行 Dog("大黄") 时，Python 自动调用这个方法。
        self 指向正在被创建的那条狗。
        """
        self.name = name      # 把传入的名字存为这条狗的属性
        self.breed = breed    # 把品种存为这条狗的属性
        self.tricks = []      # 每只狗学会的把戏列表，初始为空
    
    def learn_trick(self, trick):
        """学会一个新把戏"""
        self.tricks.append(trick)
        print(f"🐕 {self.name} 学会了【{trick}】！")
    
    def show_tricks(self):
        """展示所有学会的把戏"""
        if self.tricks:
            tricks_str = "、".join(self.tricks)
            print(f"🐕 {self.name} 会：【{tricks_str}】")
        else:
            print(f"🐕 {self.name} 还什么都不会呢，教教它吧！")
    
    def bark(self):
        """叫一声"""
        print(f"🐕 {self.name}：汪汪！")

# 创建狗对象（实例化）
dog1 = Dog("大黄")            # 默认品种是中华田园犬
dog2 = Dog("小白", "萨摩耶")  # 指定品种

# 调用方法
dog1.bark()                   # 🐕 大黄：汪汪！
dog1.learn_trick("坐下")      # 🐕 大黄 学会了【坐下】！
dog1.learn_trick("握手")      # 🐕 大黄 学会了【握手】！
dog1.show_tricks()            # 🐕 大黄 会：【坐下、握手】

dog2.bark()                   # 🐕 小白：汪汪！
dog2.learn_trick("打滚")      # 🐕 小白 学会了【打滚】！
dog2.show_tricks()            # 🐕 小白 会：【打滚】

# 每条狗是独立的，互不影响
print(f"dog1的名字：{dog1.name}，品种：{dog1.breed}")
print(f"dog2的名字：{dog2.name}，品种：{dog2.breed}")
```

**关于 `self` 的三句话理解**：

1. **`self` 不是关键字**，可以写成别的名字，但全世界的 Python 程序员都用 `self`，你不要搞特殊。
2. **`self` 代表"当前这个对象"**。`dog1.learn_trick("坐下")` 中的 `self` 就是 `dog1`。
3. **在类内部访问属性和方法都要用 `self.xxx`**。写 `self.name`，不要只写 `name`。

#### 4.3.3 一个完整的学生管理类示例

这个示例综合运用了本节课学到的大部分知识，并且与 Lesson 2-1 学过的列表和字典操作密切关联：

```python
from datetime import datetime

class StudentManager:
    """
    学生管理器：管理多个学生的信息。
    这个类使用了列表（存放所有学生）和字典（每个学生的信息）。
    """
    
    def __init__(self, class_name):
        """初始化：设置班级名称和空学生列表"""
        self.class_name = class_name
        self.students = []  # 列表 → Lesson 2-1 学过！
    
    def add_student(self, name, student_id, major=""):
        """添加一个学生（用字典存储信息 → Lesson 2-1 学过！）"""
        # 先检查学号是否重复
        for s in self.students:
            if s["学号"] == student_id:
                print(f"⚠️ 学号 {student_id} 已存在，添加失败！")
                return False
        
        student = {
            "姓名": name,
            "学号": student_id,
            "专业": major,
            "成绩": [],
            "添加时间": datetime.now().strftime("%Y-%m-%d %H:%M")
        }
        self.students.append(student)
        print(f"✓ 已添加学生：{name}（{student_id}）")
        return True
    
    def add_score(self, student_id, score):
        """为指定学号的学生添加成绩"""
        student = self._find_by_id(student_id)
        if student is None:
            print(f"⚠️ 未找到学号为 {student_id} 的学生")
            return False
        
        if score < 0 or score > 100:
            print(f"⚠️ 成绩必须在 0-100 之间，收到：{score}")
            return False
        
        student["成绩"].append(score)
        print(f"✓ {student['姓名']} 添加成绩：{score}")
        return True
    
    def get_student_info(self, student_id):
        """获取指定学生的完整信息"""
        student = self._find_by_id(student_id)
        if student is None:
            print(f"⚠️ 未找到学号为 {student_id} 的学生")
            return None
        
        scores = student["成绩"]
        info = student.copy()  # 复制一份，不影响原始数据
        if scores:
            info["平均分"] = round(sum(scores) / len(scores), 1)
            info["最高分"] = max(scores)
            info["最低分"] = min(scores)
        else:
            info["平均分"] = 0
            info["最高分"] = 0
            info["最低分"] = 0
        
        return info
    
    def list_all(self):
        """列出所有学生（含平均分排名）"""
        print(f"\n{'='*50}")
        print(f"  {self.class_name} - 学生名单（共 {len(self.students)} 人）")
        print(f"{'='*50}")
        
        if not self.students:
            print("  暂无学生")
            return
        
        # 按平均分降序排列
        sorted_students = sorted(
            self.students,
            key=lambda s: sum(s["成绩"]) / len(s["成绩"]) if s["成绩"] else 0,
            reverse=True
        )
        
        for i, s in enumerate(sorted_students, 1):
            scores = s["成绩"]
            if scores:
                avg = sum(scores) / len(scores)
                scores_str = f" | 平均分：{avg:.1f}"
            else:
                scores_str = " | 暂无成绩"
            print(f"  {i}. {s['姓名']}（{s['学号']}）{scores_str}")
    
    def get_class_stats(self):
        """获取班级整体统计数据"""
        all_scores = []
        for s in self.students:
            all_scores.extend(s["成绩"])
        
        if not all_scores:
            print("暂无成绩数据")
            return None
        
        stats = {
            "总人数": len(self.students),
            "总成绩数": len(all_scores),
            "全班平均分": round(sum(all_scores) / len(all_scores), 1),
            "全班最高分": max(all_scores),
            "全班最低分": min(all_scores),
            "及格率": round(
                len([x for x in all_scores if x >= 60]) / len(all_scores) * 100, 1
            )
        }
        return stats
    
    # 私有方法（以下划线开头，表示"内部使用"）
    def _find_by_id(self, student_id):
        """根据学号查找学生（内部方法）"""
        for s in self.students:
            if s["学号"] == student_id:
                return s
        return None


# ===== 使用 StudentManager =====

# 添加学生

# 添加成绩

sm.add_score("2024001", 90)

sm.add_score("2024002", 92)
sm.add_score("2024002", 88)
sm.add_score("2024003", 65)
sm.add_score("2024004", 55)

# 查看某个学生

# 列出所有学生

# 班级统计

print(f"\n📊 班级统计：")
for key, value in stats.items():
    if isinstance(value, float):
        print(f"  {key}：{value:.1f}")
    else:
        print(f"  {key}：{value}")
```

### 第四部分：文件操作（File I/O）

#### 4.4.1 为什么需要文件操作

到目前为止，我们写的所有程序都有一个致命问题：**程序一关，数据全没**。

```
内存（变量、列表、字典）  ←→  硬盘（文件）
    ⚡ 快，但断电就丢            🐌 慢，但永久保存
```

文件操作就是**在内存和硬盘之间搬运数据的桥梁**：

```python
# 数据只在内存中 — 程序关闭后消失
scores = [85, 90, 78]
avg = sum(scores) / len(scores)
# 程序结束，scores 和 avg 都没了

# 数据写到文件 — 永久保存
with open("scores.txt", "w", encoding="utf-8") as f:
    f.write(f"成绩：{scores}\n")
    f.write(f"平均分：{avg}\n")
# 就算电脑重启，scores.txt 还在
```

#### 4.4.2 文件打开模式

| 模式 | 含义 | 文件不存在时 | 文件已存在时 | 常用场景 |
|------|------|-------------|-------------|----------|
| `'r'` | 只读（read） | 报错 | 从开头读取 | 读取配置、读取日志 |
| `'w'` | 只写（write） | 创建新文件 | **清空**原有内容再写 | 保存新数据 |
| `'a'` | 追加（append） | 创建新文件 | 在**末尾**追加内容 | 写日志、记笔记 |
| `'r+'` | 读写 | 报错 | 从开头读写，不截断 | 修改文件内容 |
| `'x'` | 独占创建 | 创建新文件 | 报错 | 确保不覆盖已有文件 |

> **重要**：始终指定 `encoding='utf-8'`，否则中文可能乱码。这是一个**新手必踩的坑**！

```python
# 演示三种主要模式
filename = "demo_modes.txt"

# 'w' 模式：写入（覆盖原有内容）
with open(filename, "w", encoding="utf-8") as f:
    f.write("第一行：这是 w 模式写入的\n")
    f.write("第二行：前面如果有内容，会被清空\n")

# 'a' 模式：追加（在末尾添加）
with open(filename, "a", encoding="utf-8") as f:
    f.write("第三行：这是 a 模式追加的\n")
    f.write("第四行：追加的内容不会覆盖前面的\n")

# 'r' 模式：读取
with open(filename, "r", encoding="utf-8") as f:
    content = f.read()
    print("文件完整内容：")
    print(content)

# 输出：
# 第一行：这是 w 模式写入的
# 第二行：前面如果有内容，会被清空
# 第三行：这是 a 模式追加的
# 第四行：追加的内容不会覆盖前面的
```

#### 4.4.4 读取文件

```python
# 准备一个测试文件
with open("demo_read.txt", "w", encoding="utf-8") as f:
    f.write("床前明月光\n")
    f.write("疑是地上霜\n")
    f.write("举头望明月\n")
    f.write("低头思故乡\n")

# ===== 方式1：read() — 一次性读取全部内容 =====
with open("demo_read.txt", "r", encoding="utf-8") as f:
    whole = f.read()
    print("=== read() 读取全部 ===")
    print(whole)

# ===== 方式2：readline() — 逐行读取 =====
with open("demo_read.txt", "r", encoding="utf-8") as f:
    print("=== readline() 逐行读取 ===")
    line1 = f.readline()
    print(f"第1行：{line1.strip()}")  # strip() 去掉末尾的 \n
    line2 = f.readline()
    print(f"第2行：{line2.strip()}")

# ===== 方式3：readlines() — 读取所有行到列表 =====
with open("demo_read.txt", "r", encoding="utf-8") as f:
    lines = f.readlines()
    print("=== readlines() 列表方式 ===")
    print(f"共 {len(lines)} 行")
    for i, line in enumerate(lines, 1):
        print(f"  {i}: {line.strip()}")

# ===== 方式4：直接遍历文件对象（最推荐！） =====
with open("demo_read.txt", "r", encoding="utf-8") as f:
    print("=== 直接遍历（推荐） ===")
    for line in f:  # 文件对象本身支持迭代！
        print(f"  → {line.strip()}")
# 这种方式最节省内存（一行一行读，不会把整个文件都加载到内存）
```

**读取方式选择建议**：

| 场景 | 使用 |
|------|------|
| 小文件（< 1MB） | `read()` 一次性读取 |
| 大文件 / 逐行处理 | `for line in f` 直接遍历 |
| 需要随机访问某一行 | `readlines()` 拿到列表，按索引访问 |
| 只需第一行或某几行 | `readline()` |

#### 4.4.7 异常处理入门

**为什么要处理异常？** 文件操作是"高危操作"：文件可能不存在、可能没有权限、磁盘可能满了。如果不处理这些情况，程序会直接崩溃。

```python
# ===== 没有异常处理：程序直接崩溃 =====
# with open("不存在的文件.txt", "r", encoding="utf-8") as f:
#     content = f.read()
# FileNotFoundError: [Errno 2] No such file or directory: '不存在的文件.txt'
# ↑ 程序在这里就死了，后面的代码都不会执行

# ===== 有异常处理：优雅地处理问题 =====
filename = "不存在的文件.txt"

try:
    # 尝试执行可能出错的代码
    with open(filename, "r", encoding="utf-8") as f:
        content = f.read()
        print(f"成功读取！内容长度：{len(content)}字")
except FileNotFoundError:
    # 如果文件不存在，执行这里
    print(f"⚠️ 文件 '{filename}' 不存在，将创建新文件")
    with open(filename, "w", encoding="utf-8") as f:
        f.write("# 新创建的笔记文件\n")
    print(f"✓ 已创建 '{filename}'")
except PermissionError:
    # 如果没权限，执行这里
    print(f"⚠️ 没有权限访问 '{filename}'")
except Exception as e:
    # 其他所有未预期的错误
    print(f"⚠️ 发生了未知错误：{e}")
else:
    # 没有异常时才执行（可选）
    print("✓ 文件读取一切正常")
finally:
    # 无论是否发生异常都执行（可选）
    print("→ 文件操作尝试结束")

print("程序继续运行...")  # 不会因为异常而中断
```

**常见的文件操作异常**：

| 异常类型 | 什么时候发生 | 怎么避免 |
|----------|-------------|----------|
| `FileNotFoundError` | 用 `'r'` 模式打开不存在的文件 | 先用 `os.path.exists()` 检查 |
| `PermissionError` | 没有读/写权限 | 检查文件属性，或换一个有权限的目录 |
| `UnicodeDecodeError` | 编码不匹配（如用 GBK 打开 UTF-8 文件） | 始终指定 `encoding='utf-8'` |
| `IsADirectoryError` | 把目录当成文件打开 | 先用 `os.path.isfile()` 判断 |
| `OSError` | 磁盘满、路径太长等系统级错误 | 检查磁盘空间，缩短文件名 |

```python
# 一个安全的文件读取函数示例
import os

def safe_read_file(filepath, default_content=""):
    """安全地读取文件内容。如果文件不存在，返回默认值。"""
    try:
        # 检查是否是目录
        if os.path.isdir(filepath):
            print(f"⚠️ '{filepath}' 是一个目录，不是文件")
            return default_content
        
        with open(filepath, "r", encoding="utf-8") as f:
            return f.read()
    except FileNotFoundError:
        print(f"⚠️ 文件不存在：'{filepath}'，返回默认值")
        return default_content
    except PermissionError:
        print(f"⚠️ 没有权限读取：'{filepath}'")
        return default_content
    except UnicodeDecodeError:
        print(f"⚠️ 编码错误：'{filepath}' 可能不是文本文件")
        return default_content

# 测试
result = safe_read_file("不存在的笔记.md", "暂无内容")
print(f"读取结果：{result}")
```

> 📊 **企业视角：文件读写 = 企业数据流通的基础**
>
> 文件操作是程序"记住"数据的唯一方式。在企业语境中，这直接对应**数据持久化**和**系统间数据交换**。
>
> **企业场景映射**：
> | 文件操作 | 企业场景 | AI关联 |
> |---------|---------|--------|
> | **读文件（`'r'`）** | 从ERP导出CSV、读取合同PDF、加载配置文件 | **RAG（检索增强生成）的第一步就是"读取企业文档"** —— AI通过文件读取获取你的企业知识 |
> | **写文件（`'w'`）** | 生成报表、导出分析结果、保存日志 | AI分析完数据后，把结果写成文件供人工审核 |
> | **追加（`'a'`）** | 日志记录、审计追踪、增量数据收集 | AI Agent的每一步操作记录，便于事后审计和合规 |
> | **JSON读写** | API调用、系统间数据交换、配置文件 | **所有AI模型API的请求和响应都是JSON格式** ——理解JSON = 理解AI的"语言" |
> | **异常处理（try-except）** | 系统容错、降级方案 | AI应用必须有异常处理——文件不存在时给默认值而不是崩溃 |
>

```python
def celsius_to_fahrenheit(celsius):
    """摄氏度 → 华氏度"""
    fahrenheit = celsius * 9 / 5 + 32
    return round(fahrenheit, 1)

def fahrenheit_to_celsius(fahrenheit):
    """华氏度 → 摄氏度"""
    celsius = (fahrenheit - 32) * 5 / 9
    return round(celsius, 1)

def convert_temperature(value, unit_from):
    """
    统一的温度转换入口。
    
    参数：
        value: float，温度数值
        unit_from: str，'C' 表示摄氏度，'F' 表示华氏度
    
    返回：
        tuple，(转换后的数值, 目标单位)
    """
    if unit_from.upper() == 'C':
        result = celsius_to_fahrenheit(value)
        return result, 'F'
    elif unit_from.upper() == 'F':
        result = fahrenheit_to_celsius(value)
        return result, 'C'
    else:
        raise ValueError(f"不支持的温度单位：'{unit_from}'，请使用 'C' 或 'F'")
```

```python
# ========================================
# 练习2：简易图书管理系统
# ========================================
import json
import os
from datetime import datetime

class Book:
    """图书类"""
    
    def __init__(self, title, author, isbn):
        """初始化一本新书"""
        self.title = title
        self.author = author
        self.isbn = isbn
        self.is_borrowed = False       # 是否已借出
        self.borrowed_by = None        # 借书人姓名
        self.borrowed_date = None      # 借书日期
        self.history = []              # 借阅历史记录
    
    def __str__(self):
        """打印图书时的显示内容"""
        status = "📕 已借出" if self.is_borrowed else "📗 可借阅"
        info = f"《{self.title}》| {self.author} | ISBN: {self.isbn} | {status}"
        if self.is_borrowed:
            info += f" | 借阅人：{self.borrowed_by}"
        return info
    
    def borrow(self, student_name):
        """借出图书"""
        if self.is_borrowed:
            print(f"⚠️ 《{self.title}》已被 {self.borrowed_by} 借出，暂时无法借阅")
            return False
        
        self.is_borrowed = True
        self.borrowed_by = student_name
        self.borrowed_date = datetime.now().strftime("%Y-%m-%d %H:%M")
        self.history.append(f"借出：{student_name} @ {self.borrowed_date}")
        print(f"✓ 《{self.title}》已借给 {student_name}")
        return True
    
    def return_book(self):
        """归还图书"""
        if not self.is_borrowed:
            print(f"⚠️ 《{self.title}》未被借出，无需归还")
            return False
        
        return_date = datetime.now().strftime("%Y-%m-%d %H:%M")
        self.history.append(f"归还：{self.borrowed_by} @ {return_date}")
        
        print(f"✓ 《{self.title}》已归还（借阅人：{self.borrowed_by}）")
        
        self.is_borrowed = False
        self.borrowed_by = None
        self.borrowed_date = None
        return True
    
    def to_dict(self):
        """将图书信息转为字典（用于 JSON 保存）"""
        return {
            "title": self.title,
            "author": self.author,
            "isbn": self.isbn,
            "is_borrowed": self.is_borrowed,
            "borrowed_by": self.borrowed_by,
            "borrowed_date": self.borrowed_date,
            "history": self.history
        }


class Library:
    """图书馆类"""
    
    def __init__(self, name="我的图书馆"):
        """初始化图书馆"""
        self.name = name
        self.books = []  # 用列表存储所有图书对象
    
    def add_book(self, title, author, isbn):
        """添加一本新书"""
        # 检查 ISBN 是否重复
        for book in self.books:
            if book.isbn == isbn:
                print(f"⚠️ ISBN {isbn} 已存在（《{book.title}》），添加失败")
                return False
        
        new_book = Book(title, author, isbn)
        self.books.append(new_book)
        print(f"✓ 《{title}》已入库（ISBN: {isbn}）")
        return True
    
    def borrow_book(self, isbn, student_name):
        """借书：通过 ISBN 找到书，借给指定学生"""
        book = self._find_by_isbn(isbn)
        if book is None:
            print(f"⚠️ 未找到 ISBN 为 {isbn} 的图书")
            return False
        return book.borrow(student_name)
    
    def return_book(self, isbn):
        """还书：通过 ISBN 找到书并归还"""
        book = self._find_by_isbn(isbn)
        if book is None:
            print(f"⚠️ 未找到 ISBN 为 {isbn} 的图书")
            return False
        return book.return_book()
    
    def list_books(self, show_borrowed_only=False):
        """列出藏书"""
        if show_borrowed_only:
            target = [b for b in self.books if b.is_borrowed]
            section_title = "已借出图书"
        else:
            target = self.books
            section_title = "全部藏书"
        
        print(f"\n{'='*50}")
        print(f"  {self.name} - {section_title}（共 {len(target)} 本）")
        print(f"{'='*50}")
        
        if not target:
            print("  （暂无）")
            return
        
        for i, book in enumerate(target, 1):
            print(f"  {i}. {book}")
    
    def search_books(self, keyword):
        """按关键词搜索图书（搜索书名和作者）"""
        keyword = keyword.lower()
        results = []
        for book in self.books:
            if keyword in book.title.lower() or keyword in book.author.lower():
                results.append(book)
        
        if results:
            print(f"\n🔍 搜索「{keyword}」找到 {len(results)} 本：")
            for book in results:
                print(f"  - {book}")
        else:
            print(f"\n🔍 未找到包含「{keyword}」的图书")
        return results
    
    def save_to_file(self, filepath="library_data.json"):
        """将藏书数据保存到 JSON 文件"""
        data = {
            "library_name": self.name,
            "save_time": datetime.now().strftime("%Y-%m-%d %H:%M:%S"),
            "total_books": len(self.books),
            "books": [book.to_dict() for book in self.books]
        }
        
        try:
            with open(filepath, "w", encoding="utf-8") as f:
                json.dump(data, f, ensure_ascii=False, indent=2)
            print(f"✓ 藏书数据已保存到 {filepath}（共 {len(self.books)} 本）")
            return True
        except Exception as e:
            print(f"⚠️ 保存失败：{e}")
            return False
    
    def load_from_file(self, filepath="library_data.json"):
        """从 JSON 文件加载藏书数据"""
        if not os.path.exists(filepath):
            print(f"⚠️ 文件 {filepath} 不存在")
            return False
        
        try:
            with open(filepath, "r", encoding="utf-8") as f:
                data = json.load(f)
            
            self.name = data.get("library_name", self.name)
            self.books = []  # 清空现有数据
            
            for book_data in data.get("books", []):
                book = Book(
                    book_data["title"],
                    book_data["author"],
                    book_data["isbn"]
                )
                book.is_borrowed = book_data.get("is_borrowed", False)
                book.borrowed_by = book_data.get("borrowed_by")
                book.borrowed_date = book_data.get("borrowed_date")
                book.history = book_data.get("history", [])
                self.books.append(book)
            
            print(f"✓ 从 {filepath} 加载了 {len(self.books)} 本藏书（{data.get('save_time')}）")
            return True
        except Exception as e:
            print(f"⚠️ 加载失败：{e}")
            return False
    
    def _find_by_isbn(self, isbn):
        """根据 ISBN 查找图书（内部方法）"""
        for book in self.books:
            if book.isbn == isbn:
                return book
        return None


# ===== 使用示例 =====
# 创建图书馆并添加书籍
lib = Library("AI 学习图书馆")

# 查看全部藏书
```

```python
# ========================================
# 练习3：学习笔记管理器（综合练习）
# ========================================
import os
import json
from datetime import datetime

class NoteManager:
    """
    学习笔记管理器。
    
    功能：
    - 添加笔记（自动记录时间，支持标签）
    - 查看所有笔记（按时间倒序）
    - 按标签或关键词搜索笔记
    - 导出为 Markdown 文件
    - 统计笔记数量和时间分布
    """
    
    def __init__(self, data_dir="./notes"):
        """
        初始化笔记管理器。
        
        参数：
            data_dir: 笔记文件存储目录
        """
        self.data_dir = data_dir
        self.notes = []  # 所有笔记的元数据列表（用列表存字典）
        
        # 确保存储目录存在
        if not os.path.exists(data_dir):
            os.makedirs(data_dir)
            print(f"✓ 已创建笔记目录：{data_dir}")
    
    def add_note(self, title, content, tags=None):
        """
        添加一篇新笔记。
        
        参数：
            title: str，笔记标题
            content: str，笔记内容
            tags: list，标签列表（可选）
        """
        # 生成时间戳
        now = datetime.now()
        timestamp = now.strftime("%Y-%m-%d %H:%M:%S")
        # 用时间戳生成唯一文件名
        filename = now.strftime("%Y%m%d_%H%M%S") + ".md"
        filepath = os.path.join(self.data_dir, filename)
        
        if tags is None:
            tags = []
        
        # 写入 Markdown 文件
        with open(filepath, "w", encoding="utf-8") as f:
            f.write(f"# {title}\n\n")
            f.write(f"> 📅 创建时间：{timestamp}\n")
            if tags:
                f.write(f"> 🏷️ 标签：{'、'.join(tags)}\n")
            f.write(f"\n---\n\n")
            f.write(content)
        
        # 记录元数据（方便快速搜索和统计）
        note_meta = {
            "title": title,
            "filename": filename,
            "filepath": filepath,
            "timestamp": timestamp,
            "tags": tags,
            "word_count": len(content),
            "preview": content[:100] + "..." if len(content) > 100 else content
        }
        self.notes.append(note_meta)
        
        print(f"✓ 笔记已保存：《{title}》（{len(content)}字）")
        return note_meta
    
    def list_all_notes(self):
        """列出所有笔记（按时间倒序）"""
        if not self.notes:
            print("\n📝 暂无笔记，用 add_note() 添加第一篇吧！")
            return
        
        # 按时间倒序排列
        sorted_notes = sorted(
            self.notes,
            key=lambda n: n["timestamp"],
            reverse=True
        )
        
        print(f"\n{'='*50}")
        print(f"  📝 学习笔记（共 {len(sorted_notes)} 篇）")
        print(f"{'='*50}")
        
        for i, note in enumerate(sorted_notes, 1):
            tags_str = f" [{', '.join(note['tags'])}]" if note['tags'] else ""
            print(f"\n  {i}. {note['title']}{tags_str}")
            print(f"     📅 {note['timestamp']} | 📄 {note['word_count']}字")
            print(f"     📁 {note['filename']}")
            print(f"     💬 {note['preview']}")
    
    def search_notes(self, keyword):
        """
        按关键词搜索笔记（搜索标题、内容、标签）。
        由于完整内容在文件中，这里会读取文件进行全文搜索。
        """
        keyword = keyword.lower()
        results = []
        
        for note in self.notes:
            matched = False
            matched_in = []
            
            # 搜索标题
            if keyword in note["title"].lower():
                matched = True
                matched_in.append("标题")
            
            # 搜索标签
            for tag in note["tags"]:
                if keyword in tag.lower():
                    matched = True
                    matched_in.append("标签")
                    break
            
            # 搜索内容（读取文件）
            try:
                with open(note["filepath"], "r", encoding="utf-8") as f:
                    content = f.read()
                if keyword in content.lower():
                    matched = True
                    matched_in.append("内容")
            except FileNotFoundError:
                continue
            
            if matched:
                results.append({
                    **note,  # 展开原有元数据
                    "matched_in": matched_in
                })
        
        print(f"\n🔍 搜索「{keyword}」找到 {len(results)} 篇笔记：")
        for note in results:
            print(f"  - 《{note['title']}》（匹配：{'、'.join(note['matched_in'])}）")
            print(f"    📅 {note['timestamp']}")
        
        return results
    
    def filter_by_tag(self, tag):
        """按标签筛选笔记"""
        results = [n for n in self.notes if tag in n["tags"]]
        
        print(f"\n🏷️ 标签「{tag}」下有 {len(results)} 篇笔记：")
        for note in results:
            print(f"  - 《{note['title']}》（{note['timestamp']}）")
        
        return results
    
    def get_stats(self):
        """获取笔记统计信息"""
        if not self.notes:
            print("暂无笔记数据，无法统计")
            return None
        
        total_words = sum(n["word_count"] for n in self.notes)
        
        # 统计所有标签
        all_tags = {}
        for note in self.notes:
            for tag in note["tags"]:
                all_tags[tag] = all_tags.get(tag, 0) + 1
        
        # 找出最早和最新的笔记
        sorted_notes = sorted(self.notes, key=lambda n: n["timestamp"])
        first_note = sorted_notes[0]
        last_note = sorted_notes[-1]
        
        stats = {
            "总笔记数": len(self.notes),
            "总字数": total_words,
            "平均每篇字数": total_words // len(self.notes) if self.notes else 0,
            "第一篇笔记": f"{first_note['title']} @ {first_note['timestamp']}",
            "最新笔记": f"{last_note['title']} @ {last_note['timestamp']}",
            "标签统计": all_tags
        }
        
        print(f"\n{'='*40}")
        print(f"  📊 笔记统计")
        print(f"{'='*40}")
        for key, value in stats.items():
            if key == "标签统计" and value:
                print(f"  {key}：")
                for tag, count in sorted(value.items(), key=lambda x: x[1], reverse=True):
                    print(f"    - {tag}：{count}篇")
            else:
                print(f"  {key}：{value}")
        
        return stats
    
    def export_all_to_markdown(self, output_file="all_notes.md"):
        """将所有笔记合并导出为一个 Markdown 文件"""
        with open(output_file, "w", encoding="utf-8") as out:
            out.write(f"# 📝 学习笔记合集\n\n")
            out.write(f"> 导出时间：{datetime.now().strftime('%Y-%m-%d %H:%M:%S')}\n")
            out.write(f"> 共 {len(self.notes)} 篇笔记\n\n")
            out.write("---\n\n")
            
            # 按时间正序排列
            sorted_notes = sorted(self.notes, key=lambda n: n["timestamp"])
            
            for note in sorted_notes:
                out.write(f"## {note['title']}\n\n")
                out.write(f"📅 {note['timestamp']}\n\n")
                
                try:
                    with open(note["filepath"], "r", encoding="utf-8") as f:
                        content = f.read()
                    # 跳过原文件中的标题行（格式是 # 标题）
                    lines = content.split("\n")
                    # 找到 --- 分隔线后的内容
                    found_separator = False
                    for line in lines:
                        if found_separator:
                            out.write(line + "\n")
                        elif line.strip() == "---":
                            found_separator = True
                    out.write("\n")
                except FileNotFoundError:
                    out.write(f"（原始文件 {note['filename']} 不存在）\n\n")
        
        print(f"✓ 笔记已导出到 {output_file}")
        return output_file
```

## 八、常见问题（FAQ）

### Q1：函数里的 `return` 和 `print()` 有什么区别？

**A**：这是新手最容易混淆的问题。

- `print()` 是把内容**显示在屏幕上**给你看，方便调试，对程序逻辑没有影响。
- `return` 是把结果**传回给调用者**，让其他代码可以使用这个结果。

```python
def with_print(x):
    print(x * 2)  # 只是在屏幕上显示

def with_return(x):
    return x * 2  # 把结果传回去

a = with_print(5)    # 屏幕显示：10
print(a)             # 屏幕显示：None（因为 with_print 没有 return）

b = with_return(5)   # 屏幕没有显示任何东西
print(b)             # 屏幕显示：10（b 拿到了 return 的值）
```

**简单记忆**：如果你希望调用函数后拿到一个值继续用，就用 `return`；如果只想让用户看看发生了什么，用 `print`。

### Q2：什么时候该用函数，什么时候该用类？

**A**：

| 场景 | 用什么 | 例子 |
|------|--------|------|
| 只做一件具体的事 | 函数 | `calculate_bmi(70, 1.75)` |
| 需要管理一组相关的数据和操作 | 类 | `Student` 类管理名字、学号、成绩 |
| 逻辑很简单（十几行代码） | 函数 | `validate_email(email)` |
| 需要在多处维护同一套"状态" | 类 | `NoteManager` 管理所有笔记的索引 |
| 把类当作"加强版的字典" | 类 | 一个学生就是一串相关数据的集合 |

**一句话**：函数是"动词"（做一件事），类是"名词"（一个东西）。

### Q3：`self` 到底是什么？为什么每个方法里都要写？

**A**：`self` 是"我自己"的意思。当你调用 `dog1.bark()` 时，Python 内部实际执行的是 `Dog.bark(dog1)` —— 把 `dog1` 作为第一个参数传了进去。`self` 就是接收这个参数的位置。

每一个对象都有自己的属性（`self.name`、`self.scores`），`self` 就是"当前这个对象"的指代。不写 `self`，Python 就不知道你指的是哪个对象的属性。

### Q4：文件操作一定要用 `with` 吗？

**A**：**是的，一定要用。** 这不是可选项，是最佳实践。

- `with` 保证文件一定会被正确关闭，即使程序中途出错。
- 不用 `with` 的话，如果程序在 `open()` 和 `close()` 之间崩溃，文件可能损坏。
- 从今天开始养成习惯：看到 `open()` 就写成 `with open() as f:`。

### Q5：`import` 那么多方式，到底用哪个？

**A**：

```python
# 首选：清晰的，一眼就知道函数来自哪个模块
import math
print(math.sqrt(25))

# 次选：只导入需要的几个函数
from math import sqrt, pi
print(sqrt(25))

# 可选：模块名太长时起别名（特别是 NumPy、Pandas）
import numpy as np
import pandas as pd

# 禁止：污染命名空间，不知道什么来自哪里
from math import *  # 永远不要用
```

### Q7：中文在文件中显示为乱码怎么办？

**A**：99% 的情况是因为忘了写 `encoding='utf-8'`。

```python
# ❌ 没有指定编码，中文可能乱码
with open("test.txt", "w") as f:
    f.write("你好世界")

# ✅ 指定 UTF-8 编码
with open("test.txt", "w", encoding="utf-8") as f:
    f.write("你好世界")
```

> 养成肌肉记忆：每次写 `open()` 时，顺手打上 `encoding='utf-8'`。

### Q8：JSON 文件里的中文变成了 `\uXXXX` 怎么办？

**A**：这是因为 `json.dumps()` 或 `json.dump()` 没有加 `ensure_ascii=False`。

```python
import json

data = {"课程": "AI入门", "老师": "王老师"}

# ❌ 中文被转义
print(json.dumps(data))
# {"\u8bfe\u7a0b": "AI\u5165\u95e8", "\u8001\u5e08": "\u738b\u8001\u5e08"}

# ✅ 正常显示中文
print(json.dumps(data, ensure_ascii=False))
# {"课程": "AI入门", "老师": "王老师"}
```

### Q9：遇到不会写的代码怎么办？

**A**：这是 AI 时代最不该焦虑的问题。三步走：

1. **先想清楚你要什么**：输入是什么？输出是什么？中间要经过什么步骤？
2. **问 AI**：把问题描述清楚发给 ChatGPT/Claude，例如："用 Python 写一个函数，输入一个字符串，判断它是不是合法的邮箱地址"
3. **理解代码**：AI 给出的代码，逐行看，不懂的地方继续追问。**不要复制粘贴就完了！**

> 写不出来不可怕，复制粘贴不理解才可怕。

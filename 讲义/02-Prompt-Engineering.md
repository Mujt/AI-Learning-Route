## 四、核心知识点详解

### 4.1 什么是 Prompt Engineering？

#### 4.1.1 基本定义

**Prompt（提示词）** 是你与 AI 对话时输入的指令文本。

**Prompt Engineering（提示词工程）** 是系统性设计、优化和迭代提示词，以获得高质量 AI 输出的方法论。

> **一句话理解**：好的 Prompt 像一份精准的任务说明书，差的 Prompt 像一句模糊的口头交代。

#### 4.1.2 为什么 Prompt Engineering 如此重要？

AI 大模型就像一个能力极强但"不会主动思考你意图"的超级实习生。你对它说的话越清晰、越具体、越有结构，它返回的结果就越好。这不是 AI 的缺陷，而是当前大语言模型的基本工作原理决定的。

**核心逻辑**：

```
模糊输入 → 模型猜测你的意图 → 输出可能偏离预期
精准输入 → 模型明确你的需求 → 输出高度匹配预期
```

**一个直观的对比**：

| 场景 | 差 Prompt | 好 Prompt |
|------|-----------|-----------|
| 写方案 | "帮我写个方案" | "你是一位资深建筑设计师，请为大学城旁边200平米的现代风格咖啡馆写一份完整设计方案，包括空间布局、风格说明、材料选择、灯光设计和预算估算" |
| 写代码 | "写个爬虫" | "你是Python后端工程师，请写一个爬取豆瓣电影Top250的脚本，用requests+BeautifulSoup，包含异常处理和请求延时，代码注释用中文" |
| 分析数据 | "分析一下这个数据" | "你是数据分析师，这是一份电商销售数据（包含日期、产品、销售额、地区字段），请分析月度销售趋势、找出Top5产品和增长最快的地区，用要点列表输出" |

**本节课的核心目标**：让每一位同学从"随口一问"升级到"精准指令"，让 AI 成为你手中真正高效的工具。

### 4.2 RCTE 框架详解

RCTE 是本节课最核心的 Prompt 框架，几乎所有复杂提示词都可以基于此构建。你不需要背诵任何公式，只需要在使用 AI 时依次想清楚这四个要素。

```
┌──────────────────────────────────────────────────────────┐
│  R — Role（角色）      你希望 AI 扮演什么角色               │
│  C — Context（背景）   提供什么样的背景信息和约束条件         │
│  T — Task（任务）      要完成什么具体任务，如何拆分步骤       │
│  E — Example（示例）   给出什么样的参考示例来校准输出         │
└──────────────────────────────────────────────────────────┘
```

#### 4.2.1 R — Role（角色）

**为什么需要角色设定？**

当你告诉 AI "你是一位资深建筑设计师"时，模型会激活其训练数据中与"建筑设计师"相关的知识、术语、思维模式和表达风格。这比让它自己猜测"你想听什么"要准确得多。

**角色设定的三个层次**：

| 层次 | 示例 | 效果 |
|------|------|------|
| **不设角色** | "帮我写个方案" | 输出泛泛，缺乏专业深度 |
| **基础角色** | "你是一位设计师" | 有一定专业性，但仍较宽泛 |
| **具体角色** | "你是一位有15年商业空间设计经验的资深建筑设计师，擅长现代简约风格，曾为Manner Coffee等品牌做过空间设计" | 输出高度专业，术语准确，细节丰富 |

**角色设定公式**：

```
你是一位 [专业领域] 的 [资历/经验]，擅长 [具体方向]，
你的工作风格是 [风格描述]，你的受众是 [目标群体]。
```

**好 vs 差角色设定对比**：

| 差 | 好 |
|----|-----|
| "你是一个老师" | "你是一位有10年教学经验的大学写作课讲师，擅长引导零基础学生掌握学术写作方法，你的讲解风格深入浅出、善用类比，面对的是一群大二工程设计专业的学生" |
| "你是一个程序员" | "你是一位资深Python后端工程师，有8年Web开发经验，代码风格简洁规范，注释习惯用中文，习惯在代码中添加错误处理和日志记录" |

#### 4.2.2 C — Context（背景）

**为什么需要背景信息？**

背景信息是 AI 理解你"为什么问这个问题"和"需要什么样的回答"的关键。没有背景，AI 只能给出泛泛的回答。

**背景信息的五个维度**：

| 维度 | 说明 | 示例 |
|------|------|------|
| **目标受众** | 这个产出是给谁看的 | "这是一份给学院领导看的汇报" |
| **使用场景** | 在什么情况下使用 | "用于5分钟的课堂展示" |
| **限制条件** | 有什么硬性约束 | "预算不超过50万，面积约200平米" |
| **领域知识** | 需要了解什么背景 | "我们学校已有3间自习室但只能现场排队" |
| **期望风格** | 希望什么调性 | "风格专业但不沉闷，适合年轻受众" |

**好 vs 差背景信息对比**：

| 差的背景 | 好的背景 |
|----------|----------|
| "我要写一篇论文" | "我是一名大二工程设计专业的学生，需要完成一篇3000字的课程论文，题目是'AI在工程设计中的应用'。这门课是专业选修课，老师比较看重案例分析和实际应用价值。我的 deadline 是两周后，目前还在选题和资料收集阶段。" |

#### 4.2.3 T — Task（任务）

**为什么需要明确任务？**

这是 RCTE 中最核心的部分。任务描述要"具体到字节"，而不是"泛泛到章节"。一个大任务应该被拆分为多个清晰的小任务。

**任务描述的四个原则**：

1. **具体**：不是"写个方案"，而是"写一份包含空间布局规划、设计风格说明、材料选择建议、灯光设计方案和预算估算五个部分的咖啡馆设计方案"
2. **可衡量**：不是"写详细一点"，而是"每个部分300-500字，总字数控制在2500字以内"
3. **拆解**：不是"帮我分析数据"，而是"1) 读取Excel文件 2) 按月份汇总销售额 3) 找出Top5产品 4) 画出趋势图"
4. **有序**：标明步骤和优先级

**好 vs 差任务描述对比**：

| 差的任务描述 | 好的任务描述 |
|-------------|-------------|
| "帮我写个咖啡馆方案" | "请完成以下五项任务：\n1. 空间布局规划：包含座位区（至少30个座位）、吧台区（含制作区和收银区）、户外区（约30平米），画出区域划分文字示意图\n2. 设计风格说明：定位是现代简约工业风，说明色彩方案、核心设计元素、氛围营造策略\n3. 材料选择建议：地面、墙面、天花板、家具各推荐2-3种材料，说明选材理由和大致造价\n4. 灯光设计方案：分为基础照明、重点照明、氛围照明三个层次说明\n5. 预算估算：按硬装、软装、设备、预留金四个类别给出大致预算分配" |

#### 4.2.4 E — Example（示例）

**为什么需要示例？**

示例是最高效的"校准"方式。当你说"参考Manner Coffee的风格"时，比长篇描述"那种简约的、工业风的、暖暖的咖啡店"要准确得多。AI 的训练数据中有大量关于 Manner Coffee 的信息，这些信息会被自动关联和调取。

**三种示例类型**：

| 类型 | 说明 | 示例 |
|------|------|------|
| **参考对象** | 引用已有的知名案例 | "参考Manner Coffee的简约工业风设计" |
| **格式模板** | 提供期望的输出格式 | "请按照以下格式输出：1. [标题] → 2. [说明] → 3. [要点列表]" |
| **风格样本** | 提供一段期望风格的文字 | "请模仿以下文风：'这家咖啡馆的设计，不是在造一个喝咖啡的地方，而是在造一个让时间慢下来的容器。'" |

#### 4.2.5 RCTE 完整示例对比

**差的 Prompt（没有 RCTE）**：

```
帮我写个咖啡馆方案
```

**好的 Prompt（完整 RCTE）**：

```
R（角色）：
你是一位资深建筑空间设计师，有15年商业餐饮空间设计经验，
擅长现代简约风格和工业风格，曾为多个连锁咖啡品牌做过空间设计。
你的设计理念是"用最少的元素创造最舒适的体验"。

C（背景）：
- 项目地点：大学城旁边的商业街，周边有3所大学，人流量大
- 面积与预算：室内约170平米+户外约30平米，总预算50万元
- 目标客群：大学生和年轻教师，消费能力中等偏下
- 核心诉求：需要大量自习座位、免费WiFi、充足的充电插座
- 竞争环境：周边已有2家星巴克和1家瑞幸

T（任务）：
请为我设计一份完整的咖啡馆空间方案，包含以下5个部分：
1. 空间布局规划：含座位区（不少于35座）、吧台区、户外区，
   画出区域划分的文字示意图，标注大致尺寸
2. 设计风格说明：色彩方案、核心设计元素、氛围营造策略
3. 材料选择建议：地面、墙面、天花板、家具，各推荐2-3种材料
4. 灯光设计方案：基础照明、重点照明、氛围照明三个层次
5. 预算分配建议：按硬装、软装、设备、预留金四个类别给出比例

E（示例）：
整体风格参考Manner Coffee的简约工业风，
但需要比Manner更强调"自习友好"——更多长桌、更多充电位、
更柔和的灯光。可以参考代官山茑屋书店那种"书店+咖啡"的融合感。
```

**对比效果**：

使用"差 Prompt"时，AI 可能给出一个泛泛的几百字短方案，缺乏专业深度。
使用 RCTE 后，AI 会输出一份几千字的专业方案，结构清晰、细节丰富、可直接参考使用。

### 4.3 常见 Prompt 技巧大全

RCTE 是框架，以下 7 个技巧是"武器库"。一个成熟的 Prompt Engineer 会根据任务类型组合使用这些技巧。

#### 4.3.1 分步提问（Step by Step）

**原理**：大任务拆成小步骤，每次让 AI 专注解决一个问题，步步为营。

**适用场景**：复杂项目、长篇写作、多环节工作流。

**正确用法**：

```
第一轮：请先帮我列出"AI在建筑设计中的应用"这个主题的论文大纲，包含3-4个主要章节
第二轮：请展开第二章"AI辅助建筑性能分析"，包含具体的技术方法和应用案例
第三轮：请对第二章增加2-3个实际案例，每个案例200字以内
```

**错误用法 vs 正确用法**：

| 错误用法（一步到位） | 正确用法（分步推进） |
|---------------------|---------------------|
| "帮我写一篇关于AI在建筑中应用的完整论文，要3000字，包含案例" | 第1步：先要大纲 → 第2步：展开每章 → 第3步：补充案例 → 第4步：润色语言 → 第5步：检查格式 |

#### 4.3.2 格式设定（Format Specification）

**原理**：明确告诉 AI 你期望的输出格式，包括结构、标记、排版等。

**适用场景**：表格分析、结构化报告、数据库导出、代码文档。

**常用格式指令**：

| 指令 | 效果 |
|------|------|
| "请用 Markdown 表格输出" | 得到规整的表格 |
| "请用 JSON 格式输出" | 得到程序可解析的 JSON |
| "请用编号列表，每点不超过两行" | 简洁的要点列表 |
| "请用三级标题组织，每个小节200-300字" | 结构清晰的长文 |
| "代码块用```python包裹，注释用中文" | 规范的代码 |

**格式设定示例**：

```
请按照以下结构输出你的回答：

## 一、核心观点（一句话总结）
## 二、详细分析（3个要点，每个150字以内）
## 三、数据支撑（用表格呈现至少3个数据点）
## 四、实操建议（用编号列表，共3条）
## 五、风险提示（用 粗体 标注关键风险）
```

#### 4.3.3 思维链（Chain of Thought, CoT）

**原理**：要求 AI 在给出最终答案前，先展示完整的推理过程。这能显著提高复杂推理和逻辑分析类任务的准确率。

**适用场景**：数学计算、逻辑推理、复杂决策分析、多因素评估。

**核心指令**：

```
请一步一步思考（Let's think step by step）。
在给出最终答案之前，请先分析问题的各个方面，
列出你的推理过程，然后得出结论。
```

**对比示例**：

| 普通 Prompt | 带思维链 Prompt |
|------------|----------------|
| "这个项目方案有什么问题？" | "请一步步分析这个项目方案：\n第1步：从可行性角度分析\n第2步：从成本角度分析\n第3步：从风险角度分析\n第4步：从技术角度分析\n每一步请先列出观察，再给出判断依据，最后在综合分析中给出修改建议。" |

**一个完整的思维链 Prompt 模板**：

```
我需要你分析 [问题/方案]。请遵循以下思考步骤：

Step 1 — 信息梳理：列出这个问题涉及的所有关键信息
Step 2 — 因素分析：识别影响结果的3-5个核心因素
Step 3 — 优劣对比：每个因素的正面和负面影响
Step 4 — 权衡判断：基于以上分析，给出你的判断
Step 5 — 最终建议：给出1-3条可执行的建议

每一步都要详细展开，不要跳过推理过程。
```

#### 4.3.4 Few-shot（少样本示例）

**原理**：在 Prompt 中提供 2-3 个期望的回答示例，让 AI "照猫画虎"。这是成本最低但效果最显著的方式之一。

**适用场景**：需要特定输出格式、特定表达风格、特定分类标准。

**Few-shot 的标准模式**：

```
以下是一些输入和期望输出的示例：

示例1：
输入：[输入内容1]
输出：[期望输出1]

示例2：
输入：[输入内容2]
输出：[期望输出2]

示例3：
输入：[输入内容3]
输出：[期望输出3]

现在，请对以下输入给出同样格式的输出：
输入：[你要处理的内容]
```

**完整 Few-shot 示例（建筑方案评估）**：

```
你是一位建筑方案评审专家。请按照以下示例的格式和标准来评估设计方案。

【示例1】
方案描述：单体住宅，200平米，全玻璃幕墙
评审意见：
- 创新性：★★★☆☆（玻璃幕墙已是常见手法）
- 可行性：★★★★☆（结构简单，施工难度低）
- 成本控制：★★☆☆☆（全玻璃幕墙造价和维护成本高）
- 环境适配：★★☆☆☆（未考虑遮阳和保温）
- 总评：视觉效果好但实用性不足，建议增加遮阳设计和双层玻璃方案

【示例2】
方案描述：校园图书馆，5000平米，采用退台式绿化屋顶
评审意见：
- 创新性：★★★★☆（退台绿化在学生密度高的校园是亮点）
- 可行性：★★★☆☆（需解决屋顶防水和承重问题）
- 成本控制：★★★☆☆（绿化屋顶增加初期投入但长期节能）
- 环境适配：★★★★★（与校园整体生态高度融合）
- 总评：兼具功能性和生态性，建议深化结构方案后推进

现在，请评估以下方案：
方案描述：[填入你要评估的方案]
```

#### 4.3.5 负面约束（Negative Constraints）

**原理**：不仅告诉 AI "要什么"，也要告诉它"不要什么"。负面约束能有效避免 AI 的常见毛病（啰嗦、说套话、过度"AI化"）。

**适用场景**：所有场景（负面约束应该成为你 Prompt 的"默认组件"）。

**常用的负面约束指令**：

| 约束指令 | 解决的问题 |
|----------|-----------|
| "不要使用'首先、其次、最后、总而言之'这类套话" | 避免模板化表达 |
| "不要添加任何与主题无关的背景介绍" | 避免"凑字数" |
| "不要使用过于专业的术语，用大白话解释" | 确保非专业受众能听懂 |
| "不要说'这是一个很好的问题'之类的客套话，直接回答" | 避免AI的"热情综合症" |
| "如果信息不足，请直接说明'不确定'，不要猜测" | 防止幻觉 |
| "不要超过500字" | 控制输出长度 |

**完整负面约束示例**：

```
在回答时请遵守以下"不要"：
- 不要使用"在当今时代"、"随着科技的发展"这类空洞的开场白
- 不要每个段落都用"首先、其次、最后"的模板结构
- 不要添加超出我提问范围的内容
- 不要在不知道答案时编造信息——直接说"不确定"
- 不要超过800字
```

#### 4.3.6 角色扮演（Role Prompting）

**原理**：给 AI 设定一个具体的"人设"，让它在特定的知识域、表达方式、思维框架内回答。这是 RCTE 中 R 的深化应用。

**适用场景**：专业咨询、创意生成、模拟对话、教学设计。

**角色扮演的三个维度**：

```
角色 = 专业身份 + 性格特点 + 工作方式

专业身份：医生、律师、工程师、设计师、教师...
性格特点：严谨的、幽默的、耐心的、直率的...
工作方式：先分析后结论、用类比讲解、先给案例再给理论...
```

**完整角色扮演 Prompt 模板**：

```
请你扮演 [身份/角色]，具体设定如下：

1. 专业知识：
   - 你具备 [领域] 方面 [X] 年的经验
   - 你特别擅长 [具体方向1]、[具体方向2]
   - 你熟悉 [相关工具/框架/方法论]

2. 性格特点：
   - 你的表达风格是 [严谨的/活泼的/犀利的/温和的]
   - 面对不同意见时你会 [提出质疑/委婉建议/直接反驳]
   - 遇到不确定的问题时你会 [诚实说明/给出推测但标注/拒绝回答]

3. 工作方式：
   - 你会先用 [X] 方式分析问题
   - 然后给出 [Y] 类建议
   - 最后提供 [Z] 类后续行动建议
```

**角色扮演实例**：

```
请你扮演一位建筑设计课程导师，具体设定如下：

专业知识：从事建筑设计教学12年，擅长引导零基础学生建立设计思维，熟悉建筑学本科的核心课程。

性格特点：表达温和但有原则，善于用生活中的例子解释复杂的设计概念，不会直接说"你错了"而是说"我们可以换个角度看看"。

工作方式：看到学生的方案后，你会先指出2个亮点（建立信心），然后指出2个可以改进的地方（给出方向），最后给1个具体的修改建议（可执行）。

现在，请评价我的设计方案：[在下方粘贴你的方案]
```

#### 4.3.7 迭代优化（Iterative Refinement）

**原理**：很少有人能一次性写出完美 Prompt。Prompt Engineering 的本质是"对话式的持续优化"，好的 Prompt 是"聊"出来的，不是"写"出来的。

**迭代优化的标准循环**：

```
第1轮：用基础 Prompt 获得初稿
  ↓
第2轮：针对不满意的地方提出优化指令
  ↓
第3轮：补充遗漏的要求或约束
  ↓
第4轮：检查细节，做最后润色
  ↓
完成
```

**迭代优化的实战示例**：

```
第1轮 Prompt：
"帮我写一份产品的市场分析报告"

第2轮（补充背景和角色）：
"这份报告是给投资人看的，我是大学生创业者，产品是校园二手书交易小程序。请重新写。"

第3轮（调整结构）：
"结构改成这样：1) 市场规模 2) 竞品分析 3) 我们的差异化 4) 盈利模式。第3部分重点写，其他简写。"

第4轮（调整风格和数据）：
"风格再犀利一点，像投资人例会上的汇报。市场规模那段加一些具体的数字（哪怕是估计的也可以，但要标注'估算'）。竞品分析用表格对比。"
```

**迭代优化的三个原则**：

1. **每次只改一个问题**：不要一次提十几个修改意见，AI 可能顾此失彼
2. **引用具体内容**：说"把第三段关于价格的论述再展开一些"比说"再详细一点"好得多
3. **在同一个会话中迭代**：AI 记得上下文，不要每改一次就开新对话

### 4.5 Prompt 优化的 8 个技巧

以下每个技巧都配有"修改前"和"修改后"的对比，你可以直观感受优化前后的效果差异。

#### 技巧1：具体化——模糊词换成具体词

| 修改前 | 修改后 |
|--------|--------|
| "写详细一点" | "每个部分扩展到300字以上，添加2个具体的数字数据来支撑" |
| "写得好一点" | "请参考《经济学人》的写作风格，用短句，每段不超过3句话" |
| "给一些例子" | "请给出3个真实的行业案例，每个包含公司名称、具体做法和量化效果" |

#### 技巧2：结构化——长段落换成编号列表

| 修改前 | 修改后 |
|--------|--------|
| "帮我分析这个方案的问题和建议" | "请按以下结构分析：<br>1. 方案的3个亮点（各一句话）<br>2. 方案的3个问题（用'问题→后果→根因'格式）<br>3. 3条改进建议（按紧急度排序，每条给出具体执行步骤）" |

#### 技巧3：赋角色——匿名用户换成专家身份

| 修改前 | 修改后 |
|--------|--------|
| "这段代码有什么问题？" | "你是一位有10年Python经验的代码审查者。请以Code Review的标准审查这段代码：检查变量命名、异常处理、性能优化和安全隐患。" |

#### 技巧4：限范围——开放问题换成有限选择

| 修改前 | 修改后 |
|--------|--------|
| "推荐一些设计风格" | "请从以下四种风格中选择最适合大学城咖啡馆的方案，并说明选择理由：A. 简约工业风 B. 日式原木风 C. 北欧极简风 D. 复古文艺风。要求用表格对比四种风格的优缺点。" |

#### 技巧5：设标杆——没有参考换成有参考

| 修改前 | 修改后 |
|--------|--------|
| "写一篇有文采的咖啡馆介绍文案" | "请模仿MUJI無印良品的产品描述风格（简洁、留白、重质感、不煽情），为一家极简工业风咖啡馆写200字的介绍文案。" |

#### 技巧6：加尺度——无标尺换成有标尺

| 修改前 | 修改后 |
|--------|--------|
| "这个方案的成本高吗？" | "请从三个维度评估这个方案的成本，每个维度用1-10分打分，并说明评分依据：<br>- 初始投入（1=极低, 10=极高）<br>- 运营成本（1=极低, 10=极高）<br>- 性价比（1=性价比极低, 10=性价比极高）" |

#### 技巧7：明边界——开放作答换成带约束作答

| 修改前 | 修改后 |
|--------|--------|
| "介绍一下机器学习" | "请用不超过300字向一个完全不懂编程的大二工程设计学生解释什么是机器学习。要求使用至少1个生活化类比，不要使用矩阵、向量、导数等数学术语。" |

#### 技巧8：要证据——纯观点换成观点+证据

| 修改前 | 修改后 |
|--------|--------|
| "工业化风格适合我的咖啡馆吗？" | "请分析工业化风格是否适合我的咖啡馆。要求：每个观点都必须配一个具体的理由或数据支撑，不确定的地方请标注'[信息不足，建议进一步调研]'，不要给出没有依据的主观判断。" |

### 4.6 常见 Prompt 错误与修正

初学者最容易犯的 5 个 Prompt 错误及其修正方法。

#### 错误1：Prompt 过于简短和模糊

| 错误示例 | 问题分析 | 正确示例 |
|----------|----------|----------|
| "帮我写个方案" | 缺少所有关键信息：什么方案？给谁看？什么格式？多长？ | "RCTE完整写法……（参考4.2.5节）" |

#### 错误2：一次塞入太多无关要求

| 错误示例 | 问题分析 | 正确示例 |
|----------|----------|----------|
| "帮我分析一下这个数据，然后画个图，然后写个报告，然后做个PPT，对了顺便翻译成英文" | 一个Prompt塞了5个不同类型的任务，AI会顾此失彼 | 分为5个独立对话，每次专注一个任务。或者在同一个对话中分5轮进行，每轮完成一个任务再推进下一个。 |

#### 错误3：使用否定句描述而缺乏正向引导

| 错误示例 | 问题分析 | 正确示例 |
|----------|----------|----------|
| "不要写得太专业，不要用术语，不要太长，不要用表格" | 全是"不要"，AI不知道"该要什么" | "请用通俗易懂的语言，面向完全零基础的读者，控制在500字以内，用要点列表的形式输出。" |

#### 错误4：缺少输出格式约束

| 错误示例 | 问题分析 | 正确示例 |
|----------|----------|----------|
| "帮我整理一下这些信息" | "整理"是什么意思？排序？分类？总结？提取？ | "请将这些信息按以下格式整理：<br>- 用三级标题分类（共3-4个大类）<br>- 每个分类下用编号列表<br>- 每一条不超过30个字<br>- 总条数控制在15条以内" |

#### 错误5：把 AI 当成搜索引擎

| 错误示例 | 问题分析 | 正确示例 |
|----------|----------|----------|
| "2026年A股涨幅最高的股票是哪只？" | 这是一个事实查询问题，LLM的知识有截止日期，且会幻觉。这种问题应该用AI搜索引擎（Perplexity）或联网搜索功能。 | 使用Perplexity搜索："2026年A股涨幅最高的股票"，或使用ChatGPT/Claude的联网搜索功能，并要求"请引用具体的数据来源和日期"。 |

3. 描述性统计：按"实验组"分组，计算测量值1和测量值2的
   均值、标准差、最大值、最小值
4. 数据可视化（生成3张图）：
   - 图1：不同实验组的测量值1箱线图对比
   - 图2：测量值1和测量值2的散点图（按实验组着色）
   - 图3：温度与测量值1的关系图（带趋势线）
5. 结论输出：用print()输出一段分析摘要，指出各组之间是否有明显差异

代码要求：
- 每个步骤用 # === 步骤X: 标题 === 分隔
- 关键代码行要有中文注释
- 图片要设置标题、坐标轴标签、图例
- 如果Excel文件不存在，给出友好的错误提示而不是崩溃
- 中文显示要正常（设置中文字体）

输出格式：
先给出"你需要先做什么准备"(3句话)，
然后给出完整代码(用```python包裹)，
最后给出"如何运行这段代码"(3句话)。
```

**检查点**：代码是否能分段运行、注释是否清晰、是否处理了文件不存在的情况。

### 实操5：图片生成实操（12 分钟）

**场景**：使用 AI 图片生成工具（Midjourney / DALL-E / Stable Diffusion / 通义万相），尝试用 Prompt 生成图片。图片生成 Prompt 的写法和文字类 Prompt 有很大不同。

**图片生成 Prompt 的核心要素**：

```
[主体描述] + [场景/环境] + [风格/画风] + [光线/氛围] + [构图/视角] + [画质参数]
```

**5 个可直接使用的图片 Prompt 示例**：

**Prompt 1 — 建筑室内设计**（Midjourney / DALL-E）：
```
A modern minimalist coffee shop interior, 200 square meters,
industrial style with exposed concrete walls, warm wood furniture,
large floor-to-ceiling windows with natural sunlight streaming in,
cozy reading corners with bookshelves, hanging pendant lights,
students studying on laptops, 8K architectural rendering,
wide angle shot, hyperrealistic --ar 16:9
```

**Prompt 2 — 产品设计概念图**（Midjourney / DALL-E）：
```
A sleek ergonomic desk lamp designed for students, minimalist design,
matte white aluminum body, adjustable arm with warm LED light,
on a wooden desk with notebooks and a laptop, soft morning light
from window, product photography style, clean background,
3D render, 8K --ar 4:3
```

**Prompt 3 — 建筑设计外景**（Midjourney / DALL-E）：
```
Modern university library building exterior, glass and concrete facade,
green terraced roof garden, students walking on the plaza in front,
cherry blossom trees in spring, sunny afternoon, blue sky with
light clouds, architectural photography, symmetrical composition,
4K --ar 16:9
```

**Prompt 4 — 科技概念图**（Midjourney / DALL-E）：
```
Abstract visualization of artificial intelligence, glowing blue
neural network nodes and connections, dark background, futuristic
but not dystopian, clean and elegant, tech conference keynote style,
subtle gradient lighting, 4K digital art --ar 16:9
```

**Prompt 5 — 中文版（通义万相 / 文心一格）**：
```
现代简约风格咖啡馆室内设计，工业风，裸露的水泥墙面搭配暖色原木家具，
大面积落地窗，自然光充足，角落有书架和阅读区，吊灯暖光照明，
学生们在学习和聊天，建筑效果图，广角，超写实，16:9
```

**图片 Prompt 的核心技巧总结**：

| 要素 | 说明 | 示例 |
|------|------|------|
| **主体** | 画面中最重要的东西 | "a modern coffee shop interior" |
| **环境** | 主体所处的场景 | "with floor-to-ceiling windows and wooden furniture" |
| **风格** | 艺术风格或表现手法 | "architectural rendering, hyperrealistic" |
| **光线** | 光的方向、颜色、质感 | "soft morning sunlight, warm ambient lighting" |
| **构图** | 视角、焦距、比例 | "wide angle shot, symmetrical composition" |
| **画质** | 分辨率和细节程度 | "8K, highly detailed, photorealistic" |
| **比例** | 画面宽高比 | "--ar 16:9"（宽屏）或 "--ar 1:1"（方形） |

## 八、常见问题（FAQ）

### Q1: Prompt 写得越长越好吗？

**A**: 不一定。关键是**信息密度**而不是文字数量。一个 50 字的精准 Prompt 可能比一个 500 字的啰嗦 Prompt 效果好得多。判断标准是：Prompt 中的每一句话是否都在帮助 AI 更准确地理解你的需求？如果不是，就删掉。

### Q2: 同一个 Prompt 在不同的 AI 工具中效果一样吗？

**A**: 不一样。不同 AI 模型（ChatGPT vs Claude vs Gemini）的训练数据、对齐策略、回答风格都不同。同一个 Prompt 在不同工具中可能得到差异很大的结果。建议：重要任务至少用 2 个不同的 AI 工具交叉验证。另外，一个好的 Prompt 通常在不同工具中都能显著提升效果。

### Q3: 为什么同样的 Prompt 有时候得到的回答不同？

**A**: 大模型生成具有随机性（由 temperature 参数控制）。即使输入完全相同的 Prompt，每次生成的回答也可能略有不同。如果你需要更稳定的输出，可以在 Prompt 中加入"请给出确定性的回答"或在 API 调用时设置 `temperature=0`。

### Q4: AI 能记住我之前跟它说过的话吗？

**A**: 在同一个会话（Chat）中，AI 可以记住之前的对话上下文——这就是为什么你可以用"迭代优化"的方法不断调整输出。但不同的会话之间不共享记忆。所以，重要的背景信息要在每次开启新对话时重新说明，或者把上一轮的背景信息复制过来。

### Q5: 我应该选择哪个 AI 工具来学习 Prompt Engineering？

**A**: 对于零基础初学者，推荐以下优先级：
1. **Claude**（claude.ai）—— 写作和长文分析能力最强，对中文支持好，Prompt 遵循度高
2. **ChatGPT**（chatgpt.com）—— 综合能力均衡，生态最丰富，免费版可用
3. **DeepSeek**（chat.deepseek.com）—— 国内直连，中文效果优秀，性价比高
4. **通义千问**（tongyi.aliyun.com）—— 阿里出品，中文理解好，有免费额度

建议至少使用 2 个工具对比，才能更好地理解 Prompt 的通用性和工具的差异性。
